# 本番画像の構成（現在の仕様）

`STYLE.md` の共通指示文を先頭に付け、`style-reference.png` を参照してOpenAIの画像生成ツールで作成した画像を使用する。城・兵士などは透過PNG。追加ファイルは1枚300KB以下。作成日・出どころ・利用条件は `CREDITS.md`、生成原本と個別画像の対応は `asset-manifest.json` を参照する。

- `cards/card-*.png`：**カード85種**。カードキーの大文字をハイフンと小文字にする（`greatWaterSpirit` → `card-great-water-spirit.png`）。
- `cards/card-fac-*.png`：**4陣営56種**（王国15・森14・魔族15・竜12）。カードIDの `_` を `-` にした専用画像。兵士15種は盤面でも同じ透過画像を使う。対応は `js/ui/factionArt.js`、[確認一覧](review/factions-card-art/README.md)。
- `units/`：**兵士20体×青・オレンジ**、魔物12種、盤面用の精霊8種。兵士は普通の兵士・騎兵・弓兵・魔法使いの4系統、各5レアリティ。
- `castles/`：ふつうの城・とりで・魔法の塔・兵舎。各青／オレンジ×破損4段階。HP割合からUIが段階を選ぶ。チームの人数による塔・城壁の追加はUIで重ねる。
- `cards/frame-*.png`：兵士・魔法・武器・防御などのカード枠。レアリティ別の割り当てとメダル位置は `js/ui/cardFrame.js` と `css/rarity-assets.css`。
- `bg/`：盤面・タイトルの背景。配信には縮小・圧縮した `board-meadow-compact.png` と `title-compact.png` を使用。元画像も保持する。道のマスや対象の判定はHTML/CSSで重ねる。
- `fx/`：爆発・雷・回復・毒・氷・土煙・飛ぶ火の玉など。
- `ui/`：ボタン・看板・パネル・アイコン、`card-back.png`、`result-victory.png`、`result-defeat.png`、PWA用アイコン。`title-*.png` は起動時の転送を抑える小さい城・兵士の画像。
- `review/`：PRの画面確認画像と結果。ゲームの先読みとPWA保存には含めない。

画像の割り当ては `js/ui/art.js` が持ち、ルールJSONやGameの状態に画像情報を書かない。タイトル用だけを先読みし、残りは裏で読む。対戦開始時に必要な絵が未読なら進捗表示で待つ。その他の未読画像は小さい読み込み表示にし、仮の兵士や別の絵を一瞬表示しない。

## 盤面と説明を読むときの約束

- 道は現在5マス（`data/rules.json` の `laneLength`）。兵士は出した番には動かず、次の自分の番から進軍する。
- 普通の兵士は城攻めの基準、騎兵は速い。弓兵と魔法使いは動かずに射撃し、射程・帰還までの回数はカードの `range` / `stay` を読む。魔法使いは兵士も魔物もいなければ狙った城を撃つ。
- 3つ以上の城は中央広場を通る。魔物は広場に1体。2チームでは共有城が2つなので従来のレーンを使う。
- チームは城とHPを共有し、手札・兵士・コインは各人で別。席の色だけでなく、名前と席番号でも見分ける。
- 魔物は放置するほど城への攻撃が強くなる。とどめのカード報酬とラッキーは `monsters.json` / `rules.json` の値をUIに出す。
- 遊び方は操作と道の図から始め、詳しいルールは折りたたむ。図鑑の件数・4系統・射程・帰還・合成先・確率は実データから表示する。

## 音とPWAの更新

BGM・効果音は `js/ui/Music.js` と `js/ui/Sound.js` のWeb Audio合成音。外部音源の配布ファイルはない。最初の操作後に再生し、BGMと効果音を別々に設定できる。

配信するJS/CSS/JSON/画像を変更したら、次を実行し、更新された `js/ui/precache.js` も同じPRに含める。

```sh
node js/ui/build-precache.js
```

一覧と内容ハッシュで版を区別し、開いているページを閉じた次の起動で更新する。HTTP(S)が必要で、`file://` には対応しない。`/api/` はキャッシュしない。保存完了後の2回目からオフラインでひとりで遊べる。

既存のNodeサーバーには `/sw.js` と `/manifest.webmanifest`、manifestのMIMEを配信する追加が必要（ロジック担当への依頼：PR #60）。PythonのHTTPサーバーでは検証済み。WebPも既存サーバーのMIMEにないため、現状の背景はPNGを使う。
