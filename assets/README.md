# 本番画像の構成

`STYLE.md` の共通指示文を先頭に付け、`style-reference.png` を参照してOpenAIの画像生成ツールで作成した。透過PNG、全ファイル300,000バイト以下。作成日・利用条件は `CREDITS.md`、生成した原本と個別画像の対応は `asset-manifest.json` に記録している。

- `cards/card-*.png`：全71種類のカード。カードキーの大文字をハイフンと小文字に直す（例：`greatWaterSpirit` → `card-great-water-spirit.png`）。
- `cards/frame-*.png`：兵士・魔法・武器・防御の4種類の枠。実際の窓と名前の位置は `css/style.css` の `.card.has-frame` で合わせている。
- `units/`：6種類の兵士×青・オレンジ、12種類の魔物。
- `castles/`：青・オレンジの城、各4段階。HPの割合から画面側で差分を選ぶ。
- `bg/board.png`：1080×1920の背景。実際の道・マスと操作判定はHTML/CSSで上に重ねる。
- `fx/`：爆発・雷・回復・毒・氷・土煙・飛ぶ火の玉。
- `ui/`：火・水・風・土とハート・コインのアイコン、ボタン・看板・勝利帯・パネル。ボタン・看板・パネルは予備素材も含む。文字の可読性を優先する操作部分はCSSで描画している。

画像の割り当ては `js/ui/art.js` のみが持つ。カード・城・兵士・魔物・アイコンは読み込み前または失敗時に元のSVGを表示し、枠を読めないときは通常のCSSカードを表示する。演出も元のCSSによる光や揺れを残している。ルールのJSONやGameの状態には画像情報を書かない。

精霊8種は小さい精霊と、冠・金色の光輪を持つ大精霊で描き分けている。火・水・風・土の強弱は「遊び方」の矢印でも示す。

PR42対応として上位カード31種・新魔物5種・勇者の2色・合成とラッキー報酬の演出を追加した（計40点、すべて透過PNG・300KB以下）。既存の盤面やタイトル素材は維持する。
