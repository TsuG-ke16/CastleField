# Castle Field 王国UI 専用生成画像（原画2026-11-26、配信最適化2026-11-27）

原画PNGは `assets/review/kingdom-fantasy-v3/sources/` に分離し、このディレクトリでは配信用WebPを使用する。再生成は `python3 js/ui/build-kingdom-images.py`。原画14枚31,043,531バイト→配信14枚15,660,810バイト（49.6%削減）。カード・人物・装飾6枚は表示画素を完全維持、効果アイコン8枚は品質95。全14枚のアルファチャンネルは完全一致。

OpenAI画像生成で制作。参照は `assets/style-reference.png`、続いて生成したgroups.png、聖火球/闇火球は既存card-fireball.pngも参照。太いこげ茶輪郭・温かいカートゥーン・2頭身・文字なしを指定。ファイルは生成結果そのものを保存し、アトラス表示で各セルを使う。画像を単に別名コピーして200種類と数えていない。

割り当て: `js/ui/kingdomSkillArt.js`（全200ID）、`KingdomArt.js`（系統・枠・ナビ）、`cardVisuals.js`（全230カード）。`card-coverage.json` は対応漏れゼロの一覧、`image-inventory.json` は各原画像の寸法・サイズ・SHA256。

同じ効果の既存カードを流用する場合も、カード名から推測して実行時に決めず、cardVisuals.jsに明示した。通常兵士の青・オレンジの駒画像は既存のまま。生成アトラスのカード絵はカード拡大時の3Dテクスチャにも対応。

追加素材の用途はノード装飾・カード画像・UIに限定。カードの数値・効果・条件・取得経路には使用しない。出どころ・利用条件は `assets/CREDITS.md` を参照。
