# 王国の作戦卓：素材の寸法と色彩

ちびキャラと城を主役にした、木・革・紙のファンタジーUI。全ボタンを同じ生成素材の系統に揃える。

## 寸法と描画

実画面で通常ボタンは幅54〜250px・高さ44〜46px、メニューは幅336〜380px、手札パネルは高さ305〜886pxだった。同じ横長画像をこれらへ引き伸ばさない。

| 部品 | 描画の決まり |
|---|---|
| 通常ボタン | 高さ44px、左右端16px固定、中央1pxを横へ反復。2倍密度PNGの縦横を同じ0.5倍で表示 |
| タブ・設定選択 | 高さ40px、左右端14px固定、中央1px反復 |
| 大きなモード選択 | 専用に再生成した約4:1の完成画像。画像の比率に合わせてボタンの高さを決め、containで表示 |
| 横向きのモード選択 | 高さ44pxの素材へ切り替え。説明文は省き、操作名を表示 |
| 丸ボタン | 専用80×80px素材を40×40 CSS pxへ等比縮小 |
| 枠 | 透過中心の正方形素材。角14px固定、辺を同じ縮尺で反復。中心のfillは使わない |
| 紙・木目 | 128×128 CSS pxでタイル反復。縦長・横長でも模様の大きさを一定に保つ |
| カード枠 | 2:3の比率を維持。PCでも横に広げない |
| 戦場背景 | 縦・横の専用画像を切り替え、coverによる等比表示 |

ボタンの中央素材は端飾りの間だけに敷く。透明な角の下へ中央の色がはみ出さないよう、背景の描画範囲を分ける。大判は継ぎ足しを使わず、専用画像を一枚で描画する。

## 配色の役割

- **基調色**：低彩度のセージ色の草原、明るい生成りの紙。大きな面積を占める場所を静かにする。
- **支える色**：暗い中性色寄りのオーク。上部の戦況と手札をまとめる。木目は細かい同一スケールで、面積が増えても粗くならない。
- **主操作の色**：黄土色。ターン終了・使う・再戦・決定に絞る。補助操作は同じ縁を持つ生成りの素材。
- **状態の色**：選択中はくすんだ緑、危険は暗い赤、MPは灰みの青緑。文言・選択状態の印も残す。
- **文字**：明るい面は濃い茶、暗い選択面は白。生成素材の中央実ピクセルで、通常文字のコントラスト比4.5:1以上を検証する。

基調色・支える色を広く、差し色を小さく使う。ボタン全部を高彩度にせず、明度差と同じ形の素材で階層を作る。キャラクター、レアリティ、プレイヤー色は意味を持つため維持する。

## 実装と確認

`MaterialSkin.js` が初期画面と後から作るボタンを同じ素材へ割り当てる。図鑑のカード型ボタン、強化、ロビー、設定の選択肢も対象。文字・数値はHTMLに残す。

`ui-tests/materials.js` で素材の寸法、角と模様の反復、動的ボタンを含む画像適用、文字コントラスト、カードの縦横比を確認。生成元と利用条件は `CREDITS.md`、絵柄は `STYLE.md` に従う。PNGは各300KB以下。
