# 王国の作戦卓

明るい絵本の王国で、手元のカードから小さな軍を送り出す。既存のちびキャラ・城・カードを主役にし、背景とUIの素材を合わせるためのデザイン。

## 見た目の役割

- **草原と遺跡**：対戦場所。遠景と植物は端へ寄せ、兵士・魔物が立つ中央は静かにする。縦画面は `kingdom-meadow.png`、横画面・PCは `kingdom-valley.png`。
- **木と真鍮**：上部の戦況と、手元のカードラック。カードの枠が木の卓上になじむ濃さを使う。
- **羊皮紙**：読む場所。説明、図鑑、設定、ロビーに共通の生成パネルを使い、文字の下は明るくする。
- **琥珀色の革**：ターン終了、使う、再戦、決定。最も重要な操作。
- **青緑の革・エナメル**：別の遊び方、選択中の設定、王国の紋章。赤は危険・降参、青はMPなどゲーム内の意味に残す。
- **石の台座**：城の足元、進軍のマス、広場。背景に描き込まず、実際のマス数・位置に合わせてHTMLの上へ出す。

## 全画面に共通するルール

1. 画像に文字・数値を焼き込まない。ボタン、名札、説明はHTMLで重ねる。
2. 装飾の強さは主操作、補助操作、参照情報の順。図鑑やメニュー内の全ボタンを豪華にしない。
3. 読み物は羊皮紙、戦場は草原、手札は木のラック。背景素材が変わっても同じ配置と操作を保つ。
4. パネルとボタンは9-slice。角を固定し、文字の長さや画面の向きに合わせて中央を伸ばす。
5. カードのレアリティ、プレイヤーの色、危険表示を背景の配色で上書きしない。
6. タップでの演出スキップ、動きを減らす設定、キーボード操作を維持する。

生成元・利用条件は `CREDITS.md`、参照する絵柄と共通プロンプトは `STYLE.md`。配布PNGは各300KB以下。新規の素材はアトラスから切り出し、背景は縮小・減色している。
