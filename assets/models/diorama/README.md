## 2. 3D空間構造と座標一覧

座標系規約：
- **Blender**：Z-up、1 unit = 1m、北 = `+Y`、南 = `-Y`、東 = `+X`、西 = `-X`
- **glTF / Three.js（`.glb`）**：Y-up（`export_yup=True`）、`(x, y, z)_three = (x, z, -y)_blender`

### 中央広場・水路・浮遊島構造

- **中央広場 (`Central_Plaza`)**：中心 `(0.0, 0.0, 0.0)`、半径 `7.5m`。中立地帯として特定の陣営旗・紋章を置かず、中立の金製8方位コンパスローズ・石造ベンチ4脚・石灯籠8基を対称配置。
- **水系・滝 (`Water`)**：
  - 水面高さ `Z = -1.65m`（堀底 `Z = -2.55m`）。
  - 環状堀（半径 `7.8m 〜 11.4m`）の斜め4方向（NE/NW/SE/SW）の岩場湧水から水が流れ込み、4本の斜め水路（`45°, 135°, 225°, 315°`）を通って浮遊島外縁の4つの滝へ落下（`Z = -1.65m → -15.45m`）。
  - 道路は東西南北の十字軸、河川は斜め45°軸に完全分離されており、4本の石造アーチ橋（`R = 7.35m 〜 12.35m`）が堀の上を実際に渡れる構造で接続。
- **浮遊島裏面 (`Island_Base`)**：上面地形の外周頂点と完全連続した閉じた立体岩盤（最下点 `Z = -18.8m`）および周囲の浮遊小岩10基を造形。どの角度から見ても破綻なし。

## 3. カメラシステムとホーム画面回転ルール

- **共通軌道パラメータ**：
  - 軌道半径：`R_orbit = 13.194 m`（`r_back = 12.8m`, `r_side = 3.2m`）
  - カメラ高さ：`Z_cam = 11.4 m`
  - 注視距離：`target_dist = 16.2 m`（高さ `7.25〜7.75 m`）
  - 焦点距離：`24.5 mm`（36mmセンサー基準・横画角 `72.6°`）

## 5. ホーム画面への実装方式の推奨

実制作した `.glb` が **約 1.96 MB・39,686 triangles** と非常に軽量で、Three.js（既に `js/vendor/three/` が導入済み）でのモバイル動作に十分収まるため、以下の **ハイブリッド構成** を推奨します：

1. **通常モード（リアルタイム 3D）**：`castle_field_diorama.glb` を Three.js で読み込み、陣営切替時に `config/cameras.json` の円軌道（`R = 13.194m, Y = 11.4m`）に沿ってカメラをイージング補間回転させる。軽いドラッグ視差や結晶・炎の微小アニメも追加可能。
2. **軽量モード (`?fx=lite` / WebGL非対応端末)**：同一シーンから出力した `renders/mobile_01〜04_*_9x16.png`（縦画面）または `renders/07〜10_home_*.png`（横画面）を背景画像としてフォールバック表示。

### 残課題・今後の発展ポイント

- **既存ファイルへの統合（別タスク/レビュー後）**：本PRでは既存ファイル保護ルールに従い、`assets/CREDITS.md` や `js/ui/precache.js`、ホーム画面 UI コードは未変更です。ホーム画面組み込み時に `assets/CREDITS.md` への追記と `node js/ui/build-precache.js` の実行を行ってください。
- **リアルタイム3D向け動的演出（任意）**：Three.js 統合時に、魔族軍の浮遊結晶の上下浮遊回転、滝UVスクロール、炎の揺らぎ、雲の緩やかな回転を加えるとホーム画面の臨場感がさらに向上します。
- **テクスチャベイク（任意）**：現在は頂点カラー＋PBRで 1.96 MB に抑えています。さらに石積みの細密な凹凸を WebGL 上でも強調したい場合は、1024px 程度のノーマルマップ／AOベイクを追加可能です。

## 7. 再生成・再レンダリング手順

リポジトリルートで Blender 5.3 から以下を実行すると、`.blend` / `.glb` / 設定JSON / レンダリング一式を完全再現できます。

```powershell
# 1. .blend / .glb / config/*.json の再生成
"C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" --background --python assets/models/diorama/scripts/build_diorama.py

# 2. 必須10視点 + モバイル9:16 + ターンテーブル画像・動画の一括レンダリング
"C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" --background assets/models/diorama/castle_field_diorama.blend --python assets/models/diorama/scripts/render_diorama.py

# 3. .blend / .glb / 成果物の自動品質検証
"C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" --background --python assets/models/diorama/scripts/verify_diorama.py
```
