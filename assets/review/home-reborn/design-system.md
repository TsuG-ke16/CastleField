# Battle Station デザインシステム

実装：`css/home-reborn.css`、`js/ui/HomeIcons.js`、`js/ui/Home.js`。前案の白いパネル列ではなく、戦場・準備操作・補助ナビを別の領域に置く。

| 要素 | 基準 |
|---|---|
| 背景 | 深い青緑 `#102631`。文字の背後には細かい絵を置かない |
| 面 | `#193742`、高い面 `#234550`。シート・編集・選択行だけに使う |
| 文字 | 主 `#f0f4ef`、補助 `#b0c4ca`。未取得情報を仮の成績で埋めない |
| 操作 | 主要CTA `#f2a347`＋暗い文字。選択・補助 `#8ad7de` |
| 見出し | スマホ28px/900、PC40px/900。ページ見出し26px |
| 本文 | デッキ名15〜16px、操作14〜16px、補助12〜13px。ブランドとナビは11px |
| 余白 | 4px単位。基本12/16/20/24、PC列間36px |
| 角 | 開始6px、補助5px、編集面8px。ボトムシートのみ上角16px |
| 枠 | 境界 `#3b5661` の1px。全要素を囲わず、デッキ・形式は罫線で整理 |
| 影 | 戦場の浮き上がりとモーダルの階層に限定。金の内枠・光彩は使わない |
| CTA | 高さ58px、PC64px。押下で2px沈む。繰り返す光や拡大アニメーションなし |
| ナビ | 5項目。スマホ下部、PC左。選択は色＋線＋背景で示す |
| アイコン | 24pxのSVG、同じ1.7pxの線幅。意味はテキストラベルでも示す |
| 状態 | 選択＝線とチェック、無効＝disabledと理由、押下＝小さな移動、フォーカス＝明るい2px輪郭 |
| タップ | 主要操作44px以上。デッキの小さなカードも44×66px |

ゲームアートは操作の背景ではなく、これから遊ぶ内容を伝える独立したジオラマとする。通常は二つの城、4陣営は四つの拠点。カード本体の既存フレーム・絵は維持する。

`dialog.showModal()` により、シート内へのフォーカス制限、Escapeで閉じる操作、呼び出し元への復帰をブラウザに任せる。ナビはARIAでパネルと関連付け、左右／上下・Home・Endで切り替える。装飾SVGは読み上げ対象から外す。

`env(safe-area-inset-*)` と `100dvh` を使い、端末の安全領域を確保する。文字の拡大、通信失敗、オフラインでは必要に応じて縦にスクロールできる。PCはスマホ画面の拡大ではなく、戦場と準備を二列へ配置する。
