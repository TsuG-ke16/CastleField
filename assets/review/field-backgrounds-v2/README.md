# 軽量なフィールド背景6種

草原・溶岩・氷・古代遺跡・闇の森・砂漠を、平らな地面と外周の少数の小物で構成する絵柄に統一。Blenderでは地面、段丘、石、壁、木などを共通部品として作り、色や配置を変えて各ステージへ展開する。

[変更前後の一覧](index.html) ／ [素材情報と部品リスト](catalog.json)

## ゲームで使う画像

- `assets/bg/stage-*.png`：576×1024、不透明PNG。1枚150KB以下。6枚合計はcatalogの `totalRuntimeBytes` を参照。
- `sources/*.webp`：モデリングや将来の再出力向けの原画。ゲームの事前キャッシュから除外。
- `before/*.webp`：変更前の比較資料。
- `game/*.png`：既存の城・踏み石・UIに重ねた表示確認。Rendererの表示だけを切り替えた確認用で、ステージ効果は変更していない。

背景には城・キャラクター・踏み石・レーンの印を描き込まない。現在のUIが描く15個の踏み石を使い、中央の兵士や選択表示が読みやすい地面にする。地形を上下に繰り返した旧背景を、一続きの地形に置き換えた。

配信画像は従来の1080×1920という目安から、軽量表示用の576×1024へ抑えている。Blenderで使う原画は別に残し、詳細な制作資料までゲーム起動時に読み込まない。

## Blenderで作る共通部品

| 部品 | 最初の作り方 | 使い回し |
|---|---|---|
| 地面 | 平面1枚。緩い色むらはテクスチャ | 全ステージ |
| 段丘・岩棚 | 面取りした低い箱。側面は大きな面で作る | 草、玄武岩、氷、砂岩へ色替え |
| 岩 | 低分割の球を潰して2〜3形状 | 全ステージ |
| 石壁 | 箱と笠石。石ごとに細分化しすぎない | 草原・遺跡 |
| 木 | 太い幹と葉の塊2〜3個 | 草原・森。樹皮や葉脈はテクスチャ |
| 水晶・氷柱 | 5〜6角柱と先端 | 溶岩の黒曜石・氷・森へ色替え |
| 柱・アーチ | 低分割の円柱と数個の石材 | 遺跡・砂漠 |
| 小物 | 松、きのこ、灯り、サボテンを各1個 | リンク複製して外周へ配置 |

溶岩の流れは薄い面と発光色で表現する。流体シミュレーション、草の毛、葉1枚ずつのメッシュ、煙の大量パーティクルは初期版に使わない。砂や雪の細かな起伏も頂点を増やす前に色やテクスチャで試す。

## 軽さの目安

- 背景部分だけで合計4,000〜6,000三角形、2〜3マテリアルから始める。これは制作時の目標で、今回の画像に対応する完成モデルを測定した数値ではない。
- 木・岩・壁はリンク複製またはインスタンスで配置。形が同じ部品に専用テクスチャや専用マテリアルを増やさない。
- 512〜1024pxの共有テクスチャ1枚を最初の目安にする。草・砂の色むらまでメッシュ化しない。
- 灯りや溶岩は発光色を中心にし、個別のリアルタイムライトを並べない。静的な陰影は最後にベイクする。
- 地面を先に作り、既存の [フィールド配置見本](field-layout.svg) の3レーン・各5マスを置いてから、外側へ小物を足す。

この資料は背景のデザインと部品構成の案。UV展開済みのテクスチャセットや完成した3D地形ではない。原画の陰影をそのまま高さ・法線マップに変換しない。
