# ランク報酬スキン（置き場。まだゲームには入れていない）

ChatGPT で作った、ランク報酬の素材。ランクは 8つ：アイアン・ブロンズ・シルバー・ゴールド・プラチナ・ダイヤモンド・マスター・チャンピオン。
`assets/review/` の下なので、オフライン用の一覧（`precache.js`）には入らない。ゲームの `assets/ranks/` などとは混ぜていない。

- `card/card-front-<ランク>.png` … カードスキンの表（フレーム）。1024×1536・透明。窓・文字枠・左上の丸の位置は、8枚とも `css/rarity-assets.css` の共通の位置にそろえてある（ずれは数ピクセル。プラチナだけ下の文字枠が約14px低い）。右上の丸はなし
- `card/card-back-<ランク>.png` … カードスキンの裏。1024×1536・外側だけ透明
- `icon/rank-frame-<ランク>.png` … アイコンフレーム。512×512・透明（窓も透明）。元の一覧画像（約1774×887）から切り出したので、大きく出すとぼやける
- `icon/rank-emblem-<ランク>.png` … ランクエンブレム。同じく切り出し
- 色数を256色に減らして容量を小さくしている（元の絵は ChatGPT で作った原本）

## ゲームに入れる前に決めること
- 置き場所と名前（今の `assets/ranks/rank-*.png` を置き換えるか、足すか）
- `data/ranks.json` が古い9ランクのまま（アイアン〜レディアント）。8ランクの新しい名前に直すのはゲームロジック担当
- スキンを付けたカードでレアリティをどう見分けるか（案：上の真ん中の宝石にレアリティの色を重ねる）
