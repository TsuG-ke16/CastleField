# カード枠の素材マップ（立体カード用）

`assets/cards/frame-*.png` の色から、素材ごとの「マスク・高さ・法線」を自動で作ったものです。
3Dカード表示で、金属・宝石・紙・木を別々に光らせるために使います。

## ファイル（枠ごとに `<名前>/` フォルダ）
- `mask.png` … 素材マスク（RGBA）。R=金属、G=宝石、B=紙（名前帯・メダルの中・獣の窓）、A=虹色（ホログラム。frame-special だけ）。
  4つとも0なら木・革・ツタ・輪郭線（マットな素材）。枠の外は全部0。
- `height.png` … 高さ（グレー8bit）。ふちが低く、内側へ約10pxで盛り上がる。宝石は少し高く、輪郭線は少しへこむ。
  容量のため128段階にしている。
- `normal.png` … 法線マップ（OpenGL規約：緑が上向き）。アルファは枠のアルファ。
- `preview.png` … 確認用。枠 | マスク（金=金属、マゼンタ=宝石、水色=紙、虹=ホログラム） | 高さ | 法線。
- `materials.json` … ファイル一覧・素材ごとの光り方の目安・レイヤー順・CSSの窓の位置。

## 作り直し方
リポジトリのルートで `python3 assets/review/card-materials/build.py`（numpy と Pillow だけ。約15秒）。
同じ入力なら同じ結果になる。閾値は `build.py` 先頭の `T` と、`classify()` の枠ごとのルール。

## 限界（手描きではなく色で自動判定しています）
- 金属は「灰色・金色・銀青・紫」の色で判定しているため、枠によっては塗りの色面が金属扱いになる
  （weapon のオレンジ、defense の銀の板、epic の紫の地は広く金属扱い）。
- 宝石は「上下中央」「下のメダル」など位置でしぼっている。形が違うと取りこぼす。
  beast の小さな緑の宝石、legendary の王冠の赤い宝石は小さく不安定。
- defense の青い胴体のふちに、宝石と誤判定した細いマゼンタが少し残る。soldier の兜は金属ではなく金色（金属扱い）に出る。
- 紙は位置（名前帯・上のメダル）でしぼっているので、獣以外の枠でほかの場所にある薄い色は入らない。
- 輪郭線のぎざぎざや、宝石のハイライトで小さな穴・粒が残る。
- 高さは枠の形と明るさだけから作った近似。凹凸の細部（彫り）は出ない。
- special の虹色は色の鮮やかさで判定。パールの白い部分は金属（弱め）になる。
