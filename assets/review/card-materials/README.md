# カード枠の素材マップ（立体カード用）

`assets/cards/frame-*.png` の色と輪郭線から、素材ごとの「マスク・高さ・法線」を自動で作ったものです。
3Dカード表示で、金属・宝石・紙・木を別々に光らせ、飾りを浮き出させるために使います。

## ファイル（枠ごとに `<名前>/` フォルダ）
- `mask.png` … 素材マスク（RGBA）。R=金属、G=宝石、B=紙（名前帯・メダルの中・獣の窓）、A=虹色（ホログラム。frame-special だけ）。
  4つとも0なら木・革・ツタ・輪郭線（マットな素材）。枠の外は全部0。ふちは約1pxぼかしてある。
- `height.png` … 高さ（グレー8bit）。0=枠の外、1〜255=枠の中。1段が何ピクセルの高さかは `materials.json` の `heightScalePx`。
- `normal.png` … 法線マップ（OpenGL規約：緑が上向き）。アルファは枠のアルファ。高さ（小数）から作る。
- `lit.png` … 確認用。左＝左上からの光、右＝右からの光を当てた絵（暗い背景）。
  拡散（Lambert）と鏡面（Blinn-Phong）。鏡面の強さはマスクで変える：金属は強く鋭い、宝石はとても強く鋭い＋きらめき、紙と木は弱い。
  虹色は光の向きで色がずれる。人が「マップが役に立つか」を見るための絵。
- `preview.png` … 確認用。枠 | マスク（金=金属、マゼンタ=宝石、水色=紙、虹=ホログラム） | 高さ | 法線。
- `materials.json` … ファイル一覧・素材ごとの光り方の目安・高さの作り方と数値・レイヤー順・CSSの窓の位置。

## 作り方
1. **区画**：暗い輪郭線（明るさ V≦0.30）で区切られた所を「区画」に分ける（numpy の union-find）。
2. **金属・紙**：色で候補を出し、区画ごとに多数決する（5割以上なら区画ごと入れる、2割未満なら捨てる。大きすぎる区画は画素のまま）。
   金属は「開き」で木目の粒を消し、「閉じ」で飾りの切れ目をつなぎ、鋲の穴を埋め、60px未満の塊を捨てる。
   紙は上半分（メダル）は大きい面だけ、下半分（名前帯）は帯の端も残す。
3. **宝石**：確かな種から、輪郭線か大きな色の変化に当たるまで塗り広げる。種が多い小さな区画は区画ごと宝石にする。
   広がりすぎた塊は種に戻す。細い切れ端（面積÷周長が小さい・細長い）は捨てる。
   最後に、輪郭線と金属の候補を越えずに少し広げて、淡い面（ハイライト）の欠けを埋める。
4. **高さ（輪郭線のあいだをふくらませる）**：輪郭線と枠の外からの距離を自前の距離変換で求め、
   区画ごとに丸い山を作る（7pxで平らになるので、広い面は台地）。輪郭線は溝になる。
   宝石は中心まで盛り上がって高く、紙は低め（メダルや帯のふちより下がる）、金属は少し高い。
   外側のふちの面取りと、塗りの陰影（明るさのハイパス、弱め）を足す。
5. **法線**：高さ（小数）から Sobel で作る。容量のため X・Y を丸め（`normalStep`。2から始めて300KBに収まるまで上げる）、Z は計算し直す。
6. **容量**：PNG はどれも300KB以下。`lit.png` は256色に減色。`normal.png` は上の丸め。

## 作り直し方
リポジトリのルートで `python3 assets/review/card-materials/build.py`（numpy と Pillow だけ。約30秒）。
同じ入力なら、何回作ってもバイト単位で同じファイルになる。
閾値は `build.py` 先頭の `T`（素材）と `HT`（高さ）、枠ごとのルールは `candidates()`。

## 限界（手描きではなく色と輪郭線で自動判定しています）
- weapon・defense は胴体の金属板がほぼ全部金属になる（絵がそうなので、ほぼ正しい）。weapon のオレンジの塗りも金メッキ扱い。
- epic は紫の地を金属にしないようにした。ベージュ金の飾りは、影の部分が抜けてまだらに残る。
- uncommon の上の金具（メダルの下）は緑がかった灰色で、ツタと区別できず金属に入らない。下の金具は入る。
- common の上下のひし形の鋲は、中の暗い線が溝になり、少しへこんで見える。
- 輪郭線がとぎれている所では区画がつながり、多数決が効かない（画素ごとの判定のまま、まだらが残る）。
- 宝石は位置（上下中央・名前帯の両はしの丸・獣の枠）でしぼっている。形がちがう枠では取りこぼす。
  legendary の王冠の小さい宝石・beast の小さい宝石は取れているが、ふちが1〜2px欠けることがある。
- 紙は位置（名前帯・上のメダル）でしぼっているので、ほかの場所の淡い色は入らない。
- 高さは「輪郭線で区切られた所は丸くふくらむ」という近似。絵の中の重なり（どちらが手前か）は分からないので、
  奥にある飾りも同じ高さになる。塗りの暗い線（木目・彫りの線）も溝になる。
- `normalStep` が4〜6の枠（容量が大きい枠）は、法線の段差が少し目立つ。気になるなら法線をシェーダーで少しぼかす。
- special の虹色は色の鮮やかさで判定。パールの白い部分は金属（弱め）になる。
