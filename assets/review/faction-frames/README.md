# 4陣営カードの表・側面・裏

既存の `frame-legendary.png` の立体感・磨かれた素材・装飾密度を参考に、4陣営の表・側面・裏を同時に生成。王国は銀翼・王冠・青い宝石、森は編み根・琥珀・生命樹、魔族は黒鉄・骨の角・紫水晶、竜は黒い竜鋼・角・翼の紋章・紅玉。表の枠自体に陣営固有の造形を持たせ、裏面にも大きなレリーフを置いた。キャラクターの絵は入れない。

## ファイル

- `*-turnaround.png`：原本の三面図。左から表・右側面・裏。同一陣営を同時に生成して形と材料を対応させた。
- `../../cards/frame-faction-*.png`：表、512×768。絵の窓と外周は透明、名前・説明・MPの欄は空白。
- `../../skins/back-faction-*.png`：裏、512×768。中央の模様は浅いレリーフを想定。
- `../../frames/edge-faction-*.png`：右側面、64×768。表裏と同じ高さ。
- `../../frames/factions.json`：単位・寸法・座標・画像パス・実測した原画の窓の範囲。
- `construction.svg`：共通形状と接続のガイド。
- `index.html`：表・側面・裏を同じ縮尺で並べた確認ページ。HTTPサーバーで開く。

## Blenderでの構造

数値と共通外形は `factions.json` / `construction.svg` を正とする。幅64mm・高さ96mm・本体厚3.52mm（既存UIの厚み/幅0.055）、角半径3mm、面取り0.6mm。実寸を変える場合は全寸法を同じ倍率で変更する。

1. **表裏共通の板を1枚作る。** 表用と裏用の別々の外周メッシュを画像の輪郭から作らない。原画には生成上の小さな差があるため、共通の角丸長方形で揃える。
2. **縁を連続した一周の構造にする。** Z=-1.76〜-1.36mmが裏の金属レール、-1.36〜+1.36mmが芯材、+1.36〜+1.76mmが表の金属レール。芯材は王国が青いエナメル、森が編み根と木、魔族が紫の黒鉄、竜が黒い竜鋼と赤いエナメル。表裏の装飾は共通レールで受け、側面の芯材へ細かな模様の位相を無理に繋がない。
3. **四隅の留め具を表裏共有の部品にする。** 中心はX=±27mm、Y=±43mm、10×10mm、Z=-2.1〜+2.1mm。角の丸みに沿わせる。正面だけの薄い金具を別々に貼る構造にしない。これは部品の基準位置・取り付け範囲で、四角い金具の外形指定ではない。王国は宝石金具、森は琥珀を包む根、魔族は黒鉄金具、竜は金属の角の形へ造形する。王国の中央宝石と森の中央の帯は、Y=0の左右共通カラーとして追加する。
4. **表の絵・名前・説明を凹ませる。** PNGの透明な絵窓は合成用。実物を表裏へ貫通させず、絵の受け面をZ=+1.0mmに置く。絵の受け面は左11mm・上15.5mm・42×42mm。これは枠の下まで伸ばす絵の台座で、全域の可視範囲ではない。MPの丸い欄が左上に重なるため、主役の安全領域は左14.933mm・上23.333mm・34.133×34.133mm（全4陣営で透明を確認した中央256px四方）。名前と説明はJSONのfrontInsetsを参照。
5. **模様は面の内側で止める。** 表の王冠・骨の角・葉・翼の骨格は+0.9mm以内、裏の中央紋章は裏面から0.8mm以内の浅いレリーフを目安にする。既存の陰影をそのまま立体の段差に変換しない。

## 表裏の向きと継ぎ目

Blender座標はXが横、Yが上、Zが厚み。表を+Z側、裏を-Z側とする。表は-Z方向を見る。裏は+Z方向を見るので、**表の右端は、裏の画像の左端に繋がる**。上下は両面とも+Yを上に保ち、Y軸で180度回して裏を見る。

画像座標からモデル座標への換算は、表が `X=(u-256)/7.5`・`Y=(384-v)/7.5`、裏が `X=-(u-256)/7.5`・`Y=(384-v)/7.5`。画像の外形は共通でX=16〜496px・Y=24〜744px。側面の芯の範囲はX=19〜45px・Y=24〜744px。

## 原画と完成テクスチャの扱い

PNGは**造形・配色を決めるデザイン原画**。継ぎ目なくベイク済みのUVテクスチャや、高さ・法線マップではない。正面と裏面の窓や装飾にはわずかな差があるので、共通の板・縁・留め具を先に作り、原画を参照して模様を載せ、最後にUV展開・ベイクする。根・羽・翼の骨格・骨は表裏の共通レールから立ち上げる。角や中央カラーのように側面を跨ぐ部品は、表・側面・裏を別々に作らず1個の部品として回り込ませる。各陣営の `modelingNotes` も参照する。

この画像セットはBlenderでの造形用資料。ゲーム画面への接続とBlenderモデル本体は別工程。
