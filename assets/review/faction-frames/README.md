# 4陣営カードの表・側面・裏

既存の `frame-common.png` / `frame-rare.png` を絵柄・文字欄の参考にし、4陣営とも表・側面・裏を1枚の三面図として生成。外形から大きな飾りをはみ出させず、縁材と四隅の留め具が回り込む構造にした。王国は銀と青、森は木と緑・青銅、魔族は黒鉄と紫・骨、竜は銅と赤・浅い鱗模様。キャラクターの絵は入れない。

## ファイル

- `*-turnaround.png`：原本の三面図。左から表・右側面・裏。同一陣営を同時に生成して形と材料を対応させた。
- `../../cards/frame-faction-*.png`：表、512×768。絵の窓と外周は透明、名前・説明・MPの欄は空白。
- `../../skins/back-faction-*.png`：裏、512×768。中央の模様は浅いレリーフを想定。
- `../../frames/edge-faction-*.png`：右側面、64×768。表裏と同じ高さ。
- `../../frames/factions.json`：単位・寸法・座標・画像パス・実測した原画の窓の範囲。
- `construction.svg`：共通形状と接続のガイド。
- `index.html`：表・側面・裏を同じ縮尺で並べた確認ページ。HTTPサーバーで開く。

## Blenderでの構造

数値と共通外形は `factions.json` / `construction.svg` を正とする。幅64mm・高さ96mm・本体厚3.52mm（既存UIの厚み/幅0.055）、角半径3mm、面取り0.6mm。実寸を変える場合は全寸法を同じ倍率で変更する。

1. **表裏共通の板を1枚作る。** 表用と裏用の別々の外周メッシュを画像の輪郭から作らない。原画には生成上の小さな差があるため、共通の角丸長方形で揃える。
2. **縁を連続した一周の構造にする。** Z=-1.76〜-1.36mmが裏の金属レール、-1.36〜+1.36mmが芯材、+1.36〜+1.76mmが表の金属レール。芯材は王国・森が木、魔族が紫、竜が赤。側面には細かい図柄を渡さず、材料の帯を連続させる。
3. **四隅の留め具を表裏共有の部品にする。** 中心はX=±27mm、Y=±43mm、10×10mm、Z=-2.1〜+2.1mm。角の丸みに沿わせる。正面だけの薄い金具を別々に貼る構造にしない。
4. **表の絵・名前・説明を凹ませる。** PNGの透明な絵窓は合成用。実物を表裏へ貫通させず、絵の受け面をZ=+1.0mmに置く。安全な共通の絵領域は左11mm・上15.5mm・42×42mm。名前と説明はJSONのfrontInsetsを参照。
5. **模様は面の内側で止める。** 表の紋章・骨のインレイ・葉・鱗は+0.9mm以内、裏の中央紋章は裏面から0.8mm以内の浅いレリーフを目安にする。既存の陰影をそのまま立体の段差に変換しない。

## 表裏の向きと継ぎ目

Blender座標はXが横、Yが上、Zが厚み。表を+Z側、裏を-Z側とする。表は-Z方向を見る。裏は+Z方向を見るので、**表の右端は、裏の画像の左端に繋がる**。上下は両面とも+Yを上に保ち、Y軸で180度回して裏を見る。

画像座標からモデル座標への換算は、表が `X=(u-256)/7.5`・`Y=(384-v)/7.5`、裏が `X=-(u-256)/7.5`・`Y=(384-v)/7.5`。画像の外形は共通でX=16〜496px・Y=24〜744px。側面の芯の範囲はX=19〜45px・Y=24〜744px。

## 原画と完成テクスチャの扱い

PNGは**造形・配色を決めるデザイン原画**。継ぎ目なくベイク済みのUVテクスチャや、高さ・法線マップではない。正面と裏面の窓や装飾にはわずかな差があるので、共通の板・縁・留め具を先に作り、原画を参照して模様を載せ、最後にUV展開・ベイクする。側面を単純な連続材にしたため、表裏で細かい模様の位相を繋ぐ必要はない。

モード全体のUI接続とBlenderモデルの実制作は、この画像セットには含めていない。画像の使用先を勝手に既存モードへ適用していない。
