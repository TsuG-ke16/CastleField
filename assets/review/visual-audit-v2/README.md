## 作り直しが必要なもの（画像生成が必要）

| 問題 | ファイル | 理由 |
|---|---|---|
| 解像度が規格より低い | `card-beast-*.png`（12枚、256×256）、`card-weather-call.png`（448×448）、`frame-beast.png`（448×672） | 規格は絵512×512・枠512×768。拡大でごまかさない |
| 拡大で少しぼやける | `card-mana-shard.png`、`card-mana-drop.png` | 今回2.4倍・1.9倍に拡大した。暫定 |
| 絵が画像の端で切れている | `card-fire-king`（上）、`card-water-king`（上）、`card-great-water-spirit`（上）、`card-great-fire-spirit`（左）、`card-great-wind-spirit`（左）、`card-king-treasure`（左）、`card-god-shield`（下）、`card-wind-spirit`（右） | 窓の中では小さく切れて見えるだけだが、拡大表示・2.5D で目立つ |
| 同じ系統で描き方がそろっていない | 弓兵・魔法使いの系統と竜騎士・聖騎士は、絵の後ろに丸い背景（青い渦・金の光）がある。歩兵・騎兵などは背景なし | 兵士の4系統で見た目の決まりが2つある。どちらかにそろえる |
| レアリティが上がっても見た目の差が小さい | 普通の兵士の系統（歩兵→槍兵→重装兵→巨人→勇者）の巨人は鎧も飾りもなく、レアの重装兵より質素に見える | 「高いほど装備・存在感が増す」の原則 |

## 問題なかったもの

- 枠：レアリティごとの材質（木・つたと緑の宝石・銀と青い宝石・紫・金と王冠・虹）は、小さく表示しても見分けられる。窓・名前の帯・左右の丸の位置は6種類で同じ（文字・アイコンと重ならない）
- ほかのカードの絵：輪郭線・塗り・光の向きはそろっている。白・黒の縁取り（ハロー）はなかった
- サイズ：全ファイル300KB以下。直したファイルは元と同じ256色パレットのPNGで保存した（合計 2.85MB → 2.5MB）

## 3Dカード用の素材

`../card-materials/`（枠ごとの材質マスク・高さ・法線。使い方はそちらの README）。3Dカード担当の JS・CSS には手を入れていない。組み込むときは `assets/cards/materials/` に移して、PWA の一覧を作り直す。
