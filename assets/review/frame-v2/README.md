- 適応を含む合成候補は [390×844](fusion-390.jpg)・[360×640](fusion-360.jpg)
- [3Dマップのデバッグ出力](relief-debug.jpg)は上段が高さ、下段が材質。名前と数値の紙面を紙領域に指定した

コモンとレジェンドは初回に機能部品の位置と大きさがずれたため、各1回再生成。再生成でも数pxを超えるずれがあり、採用画像の装飾と材質を等比で処理し、機能部品を共通の座標で再構成した。残り5枠と窓背景は各1回の生成。枠外の薄いアルファを除去し、窓の透明領域とメダルの重なりをピクセルで確認した。

実画面では手札の名前と数値の横幅を計測し、両画面寸法で枠内に収まることを確認した。360×640では数値用アイコンを小さくし、長いカード名には小さい文字と折り返しを適用した。

`node --test` は332件すべて成功。実画面の `node ui-tests/smoke.js` と `node ui-tests/materials.js` も成功。PWAの配信一覧は468ファイル。
