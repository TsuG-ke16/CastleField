# 枠の凹凸マップ v2（新しい枠に合わせて作り直し）

`js/ui/build-card-relief.js` を、手で置いた四角形（古い枠の座標）をやめて、**枠の絵から自動で読み取る**作り方に変えた。
出力の形（`assets/cards/relief/frame-<名前>-relief.png` / `-raised.png`、大きさ、`--debug <フォルダ>`）は前と同じ。`CardRelief.js` は変えていない。

## 変えたこと
- **部品**：暗い輪郭線（明度0.3未満と、まわりより暗い茶色の線）と透明な所で区切って部品に番号をふる。輪郭線にすき間があって細い首でつながった部品は、首で切り分ける
- **高さ**：輪郭線・透明な所からの距離で部品ごとに丸くふくらませ（約7pxで平ら）、輪郭線は溝、外の形は面取り。宝石は真ん中へとがらせ、紙（名前の帯・数値の板・メダルの中）はまわりの枠より下げた。塗りの陰影は細かい凹凸として少しだけ。明るさそのものは高さにしない
- **法線**：高さから Sobel。前より強めにして、縁の面取りが拡大表示で読めるようにした
- **材質**：部品ごとに色の多数決（灰色＝鉄・銀、金色＝金、色を塗った金属、パール、紙、木・葉・布）。色だけで決まらない所だけ、枠ごとの色の手がかり（色相の範囲）を使う。座標は使わない
- **宝石**：鮮やかな宝石色を種にして同じ系統の色へ広げ、「丸くまとまる・切り子の明暗がある・枠の外形に接しない・横の真ん中にあるか左右対称の対がある」ものだけ残す。結果：アンコモン〜スペシャルは上の飾りの宝石1つ、魔物は上の緑の宝石2つ、種類の枠（兵士・魔法・武器・防御）は下の左右の宝石2つ。コモンは宝石なし
- **浮かせる部品**：枠の上の辺（列ごとのいちばん上の行で一番多い高さ）より上にはみ出す、横の真ん中寄りの部品（王冠・翼・葉・兜・本・剣・盾）と、その中に囲まれた部品、宝石。メダルとまっすぐな枠の辺は外す。コモンは真ん中の金属の板。輪郭線ごと切り抜き、ふちは1pxぼかす
- PNG の読み込みで、パレットの PNG（type 3、tRNS つき、1/2/4/8bit）も読めるようにした

## 残っていること
- 種類の枠（兵士・魔法・武器・防御）は輪郭線が太いので、高さと明るさの相関が 0.36〜0.50（テストの上限は0.6）。溝を深くすると上限を超えるので、溝は浅めにしてある
- 枠の地と輪郭線がつながった飾り（レアの翼、エピックの外側の金の巻き、スペシャルの外側の花びら）は、はみ出した列で切っているので、外側の端が少し浮かないことがある
- 材質は色で決めているので、魔物の枠の宝石の台座（金）は木のまま、レアは青い地も銀寄りになる。スペシャルはほぼ全体がパールの金属
- 魔物の枠の葉や、上の飾りの下側（王冠の下の唐草など）は、浮かせる部品に入らないものがある
- 拡大表示で種類の枠（兵士・魔法・武器・防御）は使われていないため、実画面では確かめていない（照らした確認だけ）
