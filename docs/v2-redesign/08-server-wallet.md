# 08. v2 のお財布をサーバーで持つ（コイン・交換pt・所持品）

ランクマッチ（07）の上に積んだ変更。今までの v2 は、コイン・所持品を端末の localStorage だけで持っていて、書きかえればいくらでも増やせた。
メニューの「お財布」で **サーバーに保存する** を選んだ人だけ、Rust サーバーのお財布を使う（選ばなければ今までどおり）。

## 決めたこと（**要確認**：人間に聞いたが返事がなかったので、おすすめの案で作った）

1. **端末から移すのは見た目の品（スキン）だけ**。1回だけ。ショップにある品（と最初から持っている品）だけ受け取り、ランク報酬の品は受け取らない（シーズン報酬だけでもらえる）。**コイン・交換pt は移さない**（サーバーの初期値 2400・350 から始まる）。見た目の品なら、書きかえても勝ち負けに関係しないため
2. **CPU対戦・同じ端末・合言葉対戦の報酬は、1日（UTC）に10回まで**（端末の申告でしか分からないので、上限で不正の影響を小さくする）。上限を超えた試合は、試合数・勝利数だけ数える。**ランクマッチの報酬はサーバーが決着を確かめて渡す**（上限なし）

## 数値（`data/v2/economy.json`。サーバーと画面が読む）

- `matchReward`：勝ち150・負け40・1日10回（CPU対戦など）
- `rankedReward`：勝ち150・負け40（ランクマッチ）
- `missions`：v2 のミッション6つ（`kind`：`always` / `matches` / `wins` / `gachaRolls` / `skins` / `skills`）。前は画面のコードに直接書いてあった。サーバーは、試合数・勝利数（サーバーが数えた分）・ガチャ回数・所持品の数を確かめてから渡す。`always`・`skills`（スキルの取得はサーバーが知らない）は申告を信じる。どれも1アカウント1回

## サーバー（`rust/server/src/wallet.rs`）

どれも `{ userId, secret }`（ゲストの本人確認）が要る。返事はお財布 `{ coins, points, pityCount, ownedSkins, matches, wins, gachaRolls, claimedMissions, migrated, matchRewardsLeft }`。

| URL | 送るもの | すること |
|---|---|---|
| `POST /api/economy/wallet` | — | 読むだけ |
| `POST /api/economy/migrate` | `ownedSkins` | 端末の所持品を移す（1回だけ。`added` に移した品） |
| `POST /api/economy/matchReward` | `won` | 対戦の報酬（`granted` に渡したコイン。上限なら0） |
| `POST /api/economy/mission` | `missionId` | ミッションの報酬 |
| `POST /api/economy/gacha`・`buy` | （今までどおり） | 返事に `wallet` を足した。ガチャの回数を数える |

ランクマッチが決着すると、両方のお財布にコインが入り（`lastChange.coins`）、試合数・勝利数も増える。

## 画面

- メニューの「お財布」：「サーバーに保存する」／「この端末の保存に戻す」（戻しても、サーバーの記録は残る）
- サーバーに保存しているとき：ガチャ・ショップ・対戦の報酬・ミッションはサーバー経由。起動したときにサーバーの値を読み直す（端末の値を書きかえても戻る）。失敗の理由・上限は画面の下に少し出す
- 結果画面の獲得コインは、ランクマッチならサーバーが渡した量、ほかは `economy.json` の値
- サーバーの所持品にないアイコンフレームは外す

## 一緒に直したこと

- 端末のガチャが、ランク報酬の品（`frame_*`・`back_rank_*`）も景品として引けていた → 外した（サーバー側は #219 で直してあった）
- `rust/server/tests/server_tests.rs` が、ガチャで先に引いた品を買おうとしてときどき落ちていた → 持っていない品を選ぶ

## 確かめたこと

- `cargo test`（`tests/wallet_tests.rs` 3件：移行はショップの品だけ・1回だけ・コインは移らない／1日10回まで・次の日に戻る／ミッションはサーバーの数で確かめて1回だけ。ランクマッチで勝ち150・負け40）、`node --test`（1073件）、型チェック・`npm run build`
- ブラウザ：端末のコイン 99999・偽のランク報酬を持った状態で「サーバーに保存する」→ コイン 2400、スキンだけ移り偽のフレームは移らない → ガチャ1回で 2300 → ミッションで 2450 → 端末の保存を 77777 に書きかえて読み直すと 2450

## まだやっていないこと

- 別の端末へ引き継ぐ方法（ゲスト登録は端末の localStorage にしかない。引き継ぎコードかアカウントが要る）
- サーバーのお財布で、ガチャの排出（`data/gacha.json`）・ショップの値段を画面と完全に同じにすること（今のサーバーのガチャは簡易版）
