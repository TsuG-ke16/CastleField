# 02. 画面別UI/UX＆スマホ片手設計仕様書

対象：**Track C（フロントUI/UX実装AI）**

---

## 1. 最優先ターゲットと画面原則

- **プライマリ端末**: スマートフォン縦持ち（`390×844` 基準、`360×640` でも崩れないこと）。外で片手操作しながら友達と遊べること。
- **セカンダリ端末**: PC横画面（`1280×800` / `1440×900`）・タブレット（`820×1180`）。
- **親指ゾーンの黄金比（スマホ縦）**:
  - **上部 55〜60%＝「見る世界」**（3Dの城・戦場・宝箱・商品棚）
  - **下部 40〜45%＝「親指で触る操作領域」**（出陣ボタン・手札・ターン終了・ボトムタブ）
- **桜井流・手触り原則（`CLAUDE.md` 継承）**:
  - 最初の1分で面白さが伝わる（長い説明文・フォームを最初に並べない）。
  - 演出はテンポよく、タップでスキップ可能にする。
  - 押して何も起きない操作を作らない（出せないカードは理由を明示）。
  - 攻撃ヒット時は「短いヒットストップ＋軽い画面揺れ＋大きいダメージ数字＋音」をセットで鳴らす。

## 2. 現行版で確認された致命的UIバグ（新UIで100%解消必須）

以下は PR #202 時点の実画面監査で確認された具体的な問題点。新フロントでは再発を構造上ゼロにする：

1. **ホーム（スマホ）**: 固定「対戦開始」ボタンの下に「ランクマッチ／フレンド対戦」が半分切れて覗いている。
2. **ホーム（PC左サイドバー）**: 別タブ（ガチャ／ショップ／メニュー）へ移動しても「バトル」タブが枠付き強調のまま残り、現在地が分かりづらい。
3. **ショップ（スマホ）**: 検索欄・並び替え・チェックボックス・11個のタグが上部を埋め尽くし、ファーストビューに商品が1つも映らない。
4. **メニュー**: 「自分の王国」「戦績と報酬」「遊び方と環境」の見出し文字がパネルの上枠線にめり込んでいる。
5. **デッキ編成＆編集**:
   - PC左パネルの下半分が真っ白な巨大余白。
   - 編集モーダルでサイコロ系カードの絵が空白。
   - 暗殺者カード等に `射undefined` が露出。
   - 一覧表示でカード下の説明テキスト枠が空箱のまま並んでいる。
6. **リザルト画面**: 上部の赤い勝利リボンが空っぽ＋「もう1回」ボタンに二重枠が出ている。
7. **スキルツリー詳細（スマホ）**: 閉じるボタンの裏に別枠の端がはみ出している＋木目ボタンとフラット金色ボタンが混在。
8. **バトル盤面**: レーン区切り線が薄すぎて草原に溶け、丸石が浮いているだけに見える。スマホ下部パネルの占有率が高すぎる。

## 3. 全7画面レイアウト＆UX仕様

### 画面①：ホーム（王国の玄関・バトルタブ）
**脱Webフォームの最優先画面。白い5段フォームを完全解体する。**

#### スマホ縦レイアウト（上から下）
1. **トップバー（高さ ~56px）**:
   - 左：アバター（丸枠）＋プレイヤー名＆Lvバー
   - 右：コイン表示（タップでショップへ）＋通知ベル（カラーアイコン）
2. **モード切替旗（高さ ~40px）**:
   - `通常` / `4陣営` / `クラシック` の3つを王国の旗タブで横1列表示。切替時に背景・城の演出が連動。
3. **メインステージ（画面の約55%・余白ゆったり）**:
   - 青空＋流れる雲＋**明るいトゥーン調の3D浮島ジオラマ**（低電力モード時は2Dちび城ジオラマ）。スワイプで軽く回転できる。
   - 城の足元付近に小さく `シーズン1 / ランク（エンブレム）` をさりげなく配置（タップでランク詳細へ）。
4. **親指アクションエリア（ボトムバー直上）**:
   - **作戦チップ行（1行・高さ ~52px）**:
     - 左チップ：使用デッキ（ミニカード2枚＋デッキ名）※クラシック時は「スキル数／編集」、4陣営時は「陣営紋章／変更」
     - 右チップ：対戦形式（CPUふつう / カジュアル / ランク / フレンド / 同じ端末）
     - ※タップ時のみ**下から羊皮紙ボトムシート**が開き、デッキ・難易度・対戦形式・詳細設定を変更できる（常時5段並べない）。
   - **主CTAボタン（幅90%・高さ 58px）**:
     - 新デザイン「主操作ゴールド」の大きく立体的な **「出陣する（対戦開始）」** ボタン。
5. **ボトムナビバー（固定・高さ ~64px＋safe-area）**:
   - 5タブ：`デッキ` / `ガチャ` / `バトル` / `ショップ` / `メニュー`。
   - **選択中タブだけ**がロイヤルブルー＋金縁で少し上にせり上がる（非選択タブに紛らわしい枠を付けない）。

#### PC横レイアウト（`≥ 1024px`）
- 左：コンパクトな縦ドックナビ（5タブ）。
- 中央〜全画面：3D浮島が広く映えるフルブリード背景。
- 右下：コンパクトな「作戦カード（デッキ＋対戦形式チップ＋大きなゴールド出陣ボタン）」を浮かせる（Webの白い設定フォームにしない）。

### 画面②：バトル画面（ゲームの心臓部）
**「盤面の3レーンが一目で分かる」＋「手札を触るのが気持ちいい」設計。**

#### スマホ縦レイアウト
1. **上部ミニHUD（高さ ~48px）**:
   - 左：ターン表示（`あなたの番` / `相手の番`）＋周回数
   - 中央：天候チップ（天候発生中のみ、タップで詳細ポップオーバー）
   - 右：MPゲージ（数値＋バー）、山札/捨札コンパクト表示、チャット＆メニュー丸ボタン
2. **戦場（画面の約62〜65%を確保！）**:
   - 上：相手の城（3Dまたは2D）＋木製HP看板＋相手名・手札枚数・城壁/精霊アイコン
   - 中央：**はっきり見える3本の土道／石畳レーン**（各5マス＋中央の魔物広場）。兵士・魔物が進軍し、衝突時に火花・土煙・ヒットストップ・数値ポップ。
   - 下：自分の城＋木製HP看板＋城壁/精霊アイコン
   - チュートリアル／ヒントは盤面上部に**軽い吹き出しトースト（自動フェードまたは×1タップ）**で出し、下部操作枠を圧迫しない。
3. **下部操作エリア（画面の約28〜30%にスリム化）**:
   - 操作バー（1行・高さ 44px）：左に `合成`・`コイン強化`（小ボタン）、右端に親指で押しやすいゴールドの **`ターン終了`**。
   - 手札折りたたみボタンは主張の少ない小さい `▼` アイコンのみ（「手札6枚」「横にスワイプ」等の冗長ラベル廃止）。
   - **扇状／横スクロール手札**: カードを今の約1.15倍大きく見やすく表示。
     - **シングルタップ**: カードが浮き上がり、盤面上に簡潔な効果カード＋「使う」ボタン表示（誤操作防止）。
     - **上方向ドラッグ＆ドロップ**: そのまま狙うレーン／敵城／味方兵士へ直感的にドロップして即発動（対象ハイライト付き）。
   - **防御フェーズ（`phase === 'defend'`）**: 攻撃予告ラインを盤面に出し、使える防御カードだけ光らせて「防御する / そのまま受ける」を迷わず選べる専用バーを表示。

#### PC横レイアウト
- 左70%：ワイド戦場（3D／2D）。
- 右30%：木枠の手札＆作戦ドック（2列カード配置＋下部に合成・強化・ゴールド「ターン終了」）。

### 画面③：ガチャ画面（王国の宝物庫）
- **背景**: 3Dカメラが城内の「宝物庫」へ移動（または専用の一枚絵背景）。
- **上部**: タイトル＋所持コイン＆交換ポイント＋右上に3つの小アイコンボタン（`見本` `提供割合` `履歴` → タップでモーダル表示。白いアコーディオン3段を廃止）。
- **中央（主役）**: 光の輪と台座の上に乗った **3D宝箱**（低電力時はBlender連番WebP）。
- **下部（親指ゾーン）**:
  - 天井プログレスバー（例：`エピック確定まであと 40回` を視覚バー表示）。
  - 横並び2ボタン：左 **「1回（100コイン・通常プレート）」** ／ 右 **「10連（900コイン・豪華ゴールド＋レア以上1枠確定帯）」**。
- **開封演出**: 専用オーバーレイで「宝箱が震える → 蓋が開いてレアリティ色の光柱 → カードが順番にめくれる（タップで全スキップ可）」。

### 画面④：ショップ画面（王国の露店）
- **最優先ルール**: **スマホ縦で開いた瞬間に、スクロールなしで商品カードが4〜6個表示されること。**
- **上部コントロール（コンパクト2行のみ）**:
  - 1行目：切替ピル（`コイン購入` / `ポイント交換`）＋右端に **`🔍 絞り込み`** 丸ボタン（タップした時だけ検索窓・並び替え・買えるものだけトグルが展開）。
  - 2行目：カテゴリ（すべて・兵士・城・キャラ・魔法・裏面・エフェクト等）を **横スクロール1行のタブ** で表示。
- **商品グリッド（2列スマホ / 4列PC）**:
  - 背景に木棚イメージ（`panel-shelf-wood.webp`）を敷き、商品カードにはレアリティ帯・大きめイラスト・価格付き新ボタンを配置。

### 画面⑤：デッキ編成＆カード図鑑
- **デッキ編成**:
  - 上部：デッキ枠切替（デッキ1〜4）＋コストメーター（`92/100`）＋枚数。
  - **PC左パネルの余白活用**: 扇状プレビューの下に **「デッキ構成グラフ（兵士／魔法／武器／防御の比率・コスト分布）」** を表示し、真っ白な空白をなくす。
  - カード一覧では **空のテキスト説明箱を表示しない**。絵＋名前＋コンパクトな数値バッジ（攻/HP/射/コスト）だけで美しく並べる。
  - **データ異常の防御**: 射程がない兵士に `射undefined` を絶対出さない（`range > 1` のときのみ表示）。
- **カード図鑑**:
  - カードタップで拡大詳細（既存の3Dホログラムカード鑑賞 `CardGL` をR3Fへ統合し、指でグリグリ傾けて楽しめる）。

### 画面⑥：スキルツリー（クラシック・200ノード）
- **描画エンジン**: SVG廃止 → **PixiJS（WebGL 2D）** による羊皮紙作戦図。
- **視認性のメリハリ**:
  - 200ノードが一様に見えないよう、`START`（王国紋章）と各系統の `奥義` ノードを1.4倍サイズ＋淡い光背で星座図のように目立たせる。
  - 接続線は手描きインク調の滑らかな曲線（取得済み＝鮮やかな青実線、取得可能＝金線、未接続＝薄い点線）。
- **操作**: 1本指パン・2本指ピンチズーム・ダブルタップ拡大・検索・系統フィルタ横スクロール。
- **詳細ボトムシート**: 新ボタン（取得＝ゴールド、解除＝危険ルビー）で統一し、現行のような木目／フラット混在や枠はみ出しを根絶。

---

### 画面⑦：メニュー・スキン装備・リザルト
- **メニュー**: 羊皮紙グループ見出しを枠線の外（上）または内側の専用帯に正しく配置し、めり込みバグを根絶。すべての項目にカラーアイコンを使用。
- **スキン装備**: 「現在の装備プレビュー（城＋兵士＋カード裏面）」を上（PCは左）に大きく配置し、タップ1回で着せ替え反映。
- **リザルト画面**:
  - 上部に `banner-victory-ribbon.webp`（または `defeat`）＋リボン帯の中央に「勝利！」「敗北…」テキストを確実に収める。
  - 戦績カード（ターン数・与ダメ・魔物・使用枚数・獲得コイン/EXP）をすっきり表示。
  - 下部にゴールドの **「もう1回」**（単一枠・二重枠禁止）と通常の **「ホームへ」**。

## 4. 受け入れ基準（UX検証）
- `390×844` / `360×640` / `1280×800` の3サイズで、全7画面に文字見切れ・枠めり込み・`undefined` 表示が **0件**。
- スマホのホーム・ショップ・ガチャで、主役（城／商品4件以上／宝箱）と主CTAが **初回表示（スクロールなし）** に収まる。
- 全インタラクティブ要素のタップ領域が **44×44 CSS px 以上**。
- 演出スキップ・動きを減らす設定（`prefers-reduced-motion`）に対応。
