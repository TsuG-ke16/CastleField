# 追加仕様まとめ：今のルールとの照らし合わせ（案）

> **これは案です。** CLAUDE.md のルールどおり、人間の確認を受けるまで実装しません。
> 確認後、決まったことを CLAUDE.md に反映するPRを先に出し、そのあと1機能1PRで実装します。数値はすべて仮。

もらった「追加仕様まとめ」の各項目を、今のゲーム（CLAUDE.md・`data/`・`js/game/`）と照らし合わせた。
**今のゲームにない仕組みを前提にしている項目が多い**ので、先に決めることを「確認したいこと」に分けた。

## 0. 前提のずれ（先に決めること）

| 追加仕様に出てくる言葉 | 今のゲーム | 決めること |
|---|---|---|
| SP（消費SP・SP回復） | **SP はない**。魔法のコストは **MP**（`initialMp` 10・`maxMp` 20。**自然回復なし**、マナ回復カードだけで増える） | SP ＝ MP と読みかえてよいか。「毎ターンのSP回復」は、MP の自然回復を新しく入れることになる |
| 夜／昼・夜明け（刻） | **ない**。周回ごとに変わるのは「天候」（晴れ・雨・霧・嵐・砂嵐…）だけ | 天候の1つとして「夜」を足すか、天候とは別の「時間」を新しく作るか |
| 獣キャラ・ビースト覚醒 | **ない**。兵士の系統は 普通の兵士・騎兵・弓兵・魔法使い の4つ（＋魔物の駒 `beast_*`、日本版の忍者） | 「獣」はどのカードか（魔物の駒 `beast_*` のことか、新しい系統か）。覚醒で何が変わるか |
| シビレ・やけど | **ない**。状態異常は 毒（`poison`）と 凍結（`frozen`）だけ | 新しい状態異常を足すか。足すなら効果（例：シビレ＝凍結と同じ？ やけど＝毒の火版？） |

| お城のシールド | **城壁（`armor`）** がそれにあたる（永続・上限 `armorMax` 40） | シールド＝城壁 でよいか |

## 1. 追加魔法カード

| カード | 今の仕組みで作れるか | 案（数値は仮） | 確認したいこと |
|---|---|---|---|
| チェーン・ブラスト | 新しい `effect` が要る | 対象：相手の兵士1体（`{ soldierId }`。今は相手の兵士を1体選ぶ対象がないので足す）。その兵士に X、同じマス・となりのマス・となりのレーンの同じマスの相手の兵士に X/2（切り捨て） | 「となり」の範囲。魔物も巻き込むか |
| イグニッション・バースト | 新しい `effect` | 自分の城に 3（城壁は無視）→ 相手の城に大ダメージ、または相手の全レーンの兵士にダメージ | 自傷で自分の城が落ちたら負けにするか（「必ず決着」の原則では、自滅で負けは分かりやすい） |
| シールド・ブラスト | 新しい `effect` | 自分の城壁の値ぶんのダメージを相手の城に与え、城壁は0になる。**使い切り**（今は全カードの `exhaust` を外しているので、例外として足す） | 城壁が上限40まで積めるので、40ダメージ（今の城HP 60 の2/3）は強すぎる。倍率（例：城壁の半分）か上限を決める |
| ゲイル・フォース | 新しい `effect` | 選んだレーン（`scope: "lane"`）の相手の兵士を1〜2マス戻す（自分の城の前より後ろには戻らない） | 押し戻しで弓兵・魔法使い（動かない）も戻すか |
| ムーンライズ／ドーンブレイク | 「夜」の仕組み次第（0 の表） | 天候の呪文（`changeWeather`）と同じ形で、「夜」にする／「夜」を終わらせる | 夜に何が起きるか（獣の覚醒、忍者の強化など） |
| ピュリファイ・フレア | 解毒薬（`curePoison`）＋ダメージで作れる | 自分の毒・凍結をすべて治し、相手の城に 2 | 解毒薬（スペシャル）の上位互換にならないよう、メインを使う・MP を使う、で差をつける |

- 理由（桜井流）：範囲攻撃（チェーン）は「密集させない」読み合い、自傷（イグニッション）・使い切り（シールド・ブラスト）は「大きな見返りには大きなリスク」に合う。

## 2. 先攻・後攻と後攻の補正

| 項目 | 今 | 案 | 確認したいこと |
|---|---|---|---|
| コイントス | 「ひとりで遊ぶ」は毎回ランダム（演出なし）。同じ端末・オンラインは p1 が先攻 | 画面だけの演出（UI担当）。結果はロジック側で乱数を使って席順を決める（`setup.firstPlayer` を足す）。タップで飛ばせる | オンラインでも毎回コイントスするか |
| ① SPブーストコイン | ない | 後攻の初期手札に1枚足す。MP +2（マナ回復カードと同じ。メインを使わない） | SP＝MP なら、今の「魔力のかけら」系と同じ。新カードにするか、既存のカードを配るだけでよいか |
| ② 初期アドバンテージ | `secondPlayerCastleBonus` は **0**（人間の指示で先攻・後攻を同じにした） | 後攻の城に初期の城壁 +5（`rules.secondPlayerArmor`）か、初期手札 +1（`rules.secondPlayerExtraHand`） | 前の指示（先攻・後攻を同じにする）を変えてよいか。①と②の両方か、どちらかか。シミュレーションで p1 勝率は今 49〜53% なので、補正が要るかも確かめる |

## 3. 駆け引き・演出

| 項目 | 案 | 確認したいこと |
|---|---|---|
| マリガン | 先攻・後攻が決まったあと、`start()` の前に1回だけ `game.mulligan(playerId, cardIds)`。選んだカードを山札に戻してシャッフルし、同じ枚数を引く。新しい `phase: "mulligan"` は作らず、`"ready"` のあいだだけ使える | オンラインでは全員がマリガンを終えるまで待つ。CPU はしない／`smart` はコスト高いカードを戻す、など |
| 背水の陣 | 城HPが `rules.overdriveHp`（仮：20）以下で発動。ずっと続く（HPが戻ったら切れるか要確認）。イベント `overdriveStarted` | 「SP回復+2」と「攻撃力+3」のどちらか（両方は強すぎる）。今の城HP 60 で 20 は 1/3。割合（`castleMaxHp` の 1/3）にするか |
| BGM の切り替え | 画面だけ（`js/ui/Music.js`。UI担当）。ロジックは今のイベント（`weatherChanged`・城HP）で足りる | 夜・ワールドボスは仕組みができてから |

- 背水の陣は「負けている人が逆転できる」要素だが、強すぎると「わざと削られる」方が得になる。シミュレーションで確かめる。

## 4. デッキ構築の編成ボーナス

- 今の「デッキ編成（コスト制）」（`checkCostDeck()`）に、**系統ごとの枚数でパッシブ効果**を足す形になる
- 前提として、カードに系統（例：`tribe: "beast"`）を書く必要がある。今のカードには系統がない（`role` は兵士の動き方）
- 例に出ている「獣」「兵器・罠」は今のゲームにないので、**今ある系統で例を作り直す**案：
  - 騎兵4枚以上：騎兵の速さ +1 は強すぎるので「騎兵を出したターンは動ける」など
  - 魔法使い・弓兵4枚以上：残るターン（`stay`）+1
  - 城攻め魔法4枚以上：MP コスト −1（最低1）
- 確認したいこと：どの系統を作るか。共通の山札（`"shared"`）では効かせない（編成していないので）でよいか

## 5. ステージ（マップ）

- 今の「天候」と役割が重なる（溶岩＝晴れ、氷＝雨／凍結、砂漠＝砂嵐）。**マップ＝「その試合ずっと続く、出やすい天候と固有ギミック」**としてまとめる案
  - `data/stages.json` を足し、`new Game({ stage })`。`weather.json` の出やすさをマップごとに上書きできるようにする
- 各マップ

| マップ | 案 | 確認したいこと |
|---|---|---|
| 草原・王都 | ギミックなし（今と同じ） | — |
| 溶岩 | 周回の始めに全員の城と兵士に1（砂嵐と同じ仕組み）。火属性・城への魔法 +3 | 「溶岩マス」「噴火」は、マスごとの地形という新しい仕組みが要る。まず全体ダメージだけでよいか |
| 氷 | 「スリップで1マス余分に進む」と「移動 −1」は逆向き。どちらか | 片方に決める。凍結の魔法の回数 +1、城壁 +1 |
| 古代遺跡 | MP の回復（自然回復がないので新しく入れる）・魔法 +2 | — |
| 闇の森 | 「夜」が長い | 夜の仕組みが先 |
| 砂漠 | 砂嵐が出やすい。弓兵・魔法使いの `range` −1 | — |

- 選び方：対戦はランダムか部屋主が選ぶ。ワールドレイドの専用マップは、レイドができてから

## 進め方の案（1機能1PR）

0. この照らし合わせへの返事をもらい、CLAUDE.md を直すPR（2人の承認が必要）
1. **すぐ作れるもの**：ゲイル・フォース、ピュリファイ・フレア、マリガン、先攻・後攻の決め方（ロジック）＋コイントス演出（UI）
2. **前提を決めれば作れるもの**：チェーン・ブラスト、イグニッション・バースト、シールド・ブラスト、後攻の補正、背水の陣
