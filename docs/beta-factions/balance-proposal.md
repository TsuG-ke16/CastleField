# 4陣営 バランス調整の提案（数値は変更していない）

カードの確定仕様は変更していない。以下は**提案**で、採用するかは人間が決める。

## 気づいたこと

1. **森が極端に弱い**（どの相手にも1〜2割）。#178 の測定と同じ。
2. **試合が長い**：王国どうしは平均133手番（ターン数。1人あたり約66）で、67%が「崩壊の刻」（時間切れ）で決着。10分前後の目安より長い。
3. 実サーバーでの簡易ボット対戦（出せるものを順に出すだけ）では、魔物の放置で城が落ちて終わる試合が複数あった（ベータの2人対戦でも起きうる。魔物を倒す動機は強いが、見落とすと突然負ける）。
4. 反応（属性の組み合わせ）は、魔族どうし（9.6回/試合）以外ではあまり起きない。王国×竜はほぼ0.3回で「属性を楽しむ」遊びになっていない。

## 提案（#178 のPR本文の測定に基づく。再測定してから採用を判断する）

| 案 | 内容 | 期待（森 vs 王国・魔族・竜の勝率） |
|---|---|---|
| A | 森の攻撃魔法と精霊の MP を1ずつ下げる | 5%・28%・16% → 37%・66%・57%（#178 の測定） |
| B | A に加えて、森の兵士を各3枚にする | 44%・63%・68%（強くなりすぎる可能性。遊んで確かめる） |
| C | 城HP 60 → 45 | 平均93手番・崩壊の刻 24%（#178 の測定） |
| D | 崩壊の刻の予告30周・開始40周に早める | 平均84手番 |

おすすめ：**A + C**（まず森の MP を下げ、城HPを下げて試合を短くする）。B は A のあとにもう一度測って、足りなければ。
属性反応が起きにくい点（気づき4）は、各陣営の属性付与カードの枚数を増やす案が考えられるが、仕様の変更になるため、まず実際に遊んでから決める。

桜井流の原則に照らすと、森は「長所：精霊・回復で粘る／短所：攻めが遅い」のはずが、実際には短所だけが目立っている。**威力ではなく、MP・枚数で調整する**（案A）のが原則に合う。
