# 4陣営（ベータ）— 先行プレイ版

友達と4陣営モードをオンライン対戦するためのベータ版。**カードの数値・効果は #178 の確定仕様のまま変えていない**（バランスは `balance-proposal.md` に提案としてまとめた）。

## 遊び方（アクセス方法）

1. リポジトリのルートで `node server/server.js`（既定ポート 8787。`PORT` で変更）
2. 2人とも `http://<サーバー>:8787/?beta=factions` を開く（`?mode=factions` でも同じ）。**このパラメータがないと通常モードのまま**で、4陣営の入口は出ない
3. 同じ合言葉を入れて「部屋に入る」
4. 席ごとに「陣営」を選ぶ（王国・森の同盟・魔族軍・竜族帝国）。相手の選択もすぐ画面に出る。「陣営の説明」で各陣営の説明と全カード（絵・MP・枚数・効果）が見られる
5. 部屋主が「対戦をはじめる」。決着後は「もう1回」（同じ陣営で再戦）か「部屋に戻る」（陣営を変えられる）

ページを読み直しても、同じ URL（`?beta=factions` つき）なら元の部屋につなぎ直す。

## 通常モードとの分離

- タイトルの入口は URL パラメータだけ（本番のメニューには出さない）。限定公開は、このURLを知っている人だけ。
- **ランク戦・ショップ・ミッション・ガチャは出さない**（ベータ中はホーム画面を通らず、合言葉の部屋に直行）。
- **戦績・経験値・コイン・ミッションに記録しない**：`data/modes.json` の `beta: true` のモードは、`Room.finishMatch` が `onMatchEnd` を呼ばない（`tests/factions-server.test.js` で確認）。
- 「ひとりで遊ぶ」「同じ端末」「`?debug=1`」はベータでは使えない（オンライン専用。押すと理由を出す）。
- 画面左上に常に「4陣営（ベータ）」の目印。部屋にも「結果は記録されません」と出す。
- 通常モード・クラシックのコード・データ（`js/game/`、`data/cards.json`、`data/rules.json`、`data/classic/`）は変えていない。

## 既知の不具合・未実装

- **ベータは オンライン専用**。ひとりで遊ぶ（CPU）は未対応（部屋に CPU を足すことはサーバー側でできるが、画面は「部屋の CPU 追加」の確認が不十分）。
- 演出は最小限：属性反応は名前＋属性アイコンの表示と画面の揺れだけ。専用エフェクト・効果音なし。血の膜・城の身代わり・回復減少は常時バッジではなく、起きたときの表示のみ。
- カードは通常の2D表示（3Dフレームなし）。3D拡大表示を長押しで開くと、ベータのカードで見た目が崩れないかは未確認。
- 部屋の「ルールを変更」にある項目のうち、4陣営で意味のないもの（山札の形・チーム）は隠したが、「ステージ」「城のHP」は選べる。
- 4人以上・チーム戦は断る（サーバー仕様）。2人対戦のみ確認。広場（3人以上）の画面は未検証。
- 森の同盟が弱い・試合が長い（`balance-proposal.md`）。魔物の放置で城が落ちて決着する試合が多い。
- 本番公開の前に決めること：`available:false` のモードに `mode` 指定で入れる問題（#182 の「人間が決めること」①）は、ベータの試合を記録しないことで影響を止めたが、入口を閉じる仕組み（環境変数など）は入れていない。
