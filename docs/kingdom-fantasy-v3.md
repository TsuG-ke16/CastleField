# PR #202 第3版の仕上げ（2026-11-27）

王国ファンタジーの配色、専用スキル絵、奥義枠、CPU選択の絵と構成を維持し、配置・配線・読みやすさ・配信サイズを仕上げた。ゲームルール、効果、取得条件、カード数値、CPU戦略は変更していない。

## スキルツリー

- 四角い19区画を撤去。紋章と淡い色のまとまりを添えた内外の枝配置へ変更。既存の200枚の効果絵・奥義装飾・通常/横断/STARTの枠を維持。
- 重なった直交幹線を撤去し、286辺それぞれを一意の曲線へ変更。ノードの縁で終端を切り、ほかのノードを避ける候補を選ぶ。交差には羊皮紙色の縁を付け、同じ線に見える重複を防ぐ。
- ノード選択時に実際の直接接続だけを青で強調し、接続先にも印を付ける。詳細の「つながるスキル」は元の隣接表から作り、名前を押すとそのノードへ移動する。
- 地図上の内部IDを優先する表示をやめ、拡大時にスキル名を2行で表示。検索結果・詳細・接続先も名前を先に表示し、ID検索は維持。
- 取得可能=金と＋、取得済み=青と✓、条件不足=破線、未接続=点線。休眠はモデルの実装状態から「休」と紫の線種を付ける。効果の発動仕様や取得可否をUIで変更しない。
- スマホ横向きでは検索・系統を初期折りたたみにし、専用ボタンで開閉。開閉や詳細の出現で地図の寸法が変わっても、48pxの当たり領域と座標変換を更新する。
- マウス連続クリックをタッチのダブルタップと取り違えないようにした。
- 第2版の最終整理で残った未定義の座標参照を修正。今回のブラウザ検証は修正後の最終コードから実施した。

表示座標はskillTreeLayout.js、曲線はskillTreePaths.js。曲線は `node js/ui/build-skilltree-paths.js` で事前生成し、初期表示のたびに経路探索しない。新しいゲームの接続を作らず、元のedgeListを読み取るだけ。

比較は同じChromium/1440×900/コールドコンテキスト、ソフトウェア描画環境で90フレーム。レイアウトと描画処理の変更も含む比較で、圧縮だけの効果とは分離していない。単発のスモーク計測であり、実機や60fpsを保証するベンチマークではない。第2版はそのままでは座標参照エラーで起動できないため、その1行だけを修正した分離チェックアウトを比較対象にした。詳細はperformance.json。

- 原画PNG14枚は `assets/review/kingdom-fantasy-v3/sources/` に保存。配信用は `assets/ui/kingdom-v2/*.webp`。原画を捨てず、既存の絵を描き替えない。
- カード・人物・紋章・枠の6枚は無劣化で表示画素を維持。効果アイコン8枚は品質95。全14枚でアルファチャンネルを完全一致と検証。効果アイコンのクリーム背景合成PSNRは35.76〜36.81dB。これら8枚を無劣化とは呼ばない。
- 再生成は `python3 js/ui/build-kingdom-images.py`（Pillow/libwebp）。途中ファイルを配信しないよう一時ファイルから置換する。
- ツリー用SVG画像421要素のURL設定を画面を開く時まで遅らせる。8枚の効果アトラスはツリーを開くまで地図DOMから要求しない。系統フィルタの共有紋章は先行して読める。複数ノードは同じアトラスを共有する。
- **オフラインを維持するため、PWA初回キャッシュは配信WebP14枚を背景で保存する。** 完全な「訪問した画面だけキャッシュ」へは変更していない。原画はreview/なのでPWAキャッシュには入らない。
- HTTPサーバーには `.webp: image/webp` の静的MIME定義1行だけ追加。ゲーム/API処理・サーバールールは変更なし。SWの更新・配信一覧を再生成。

## 文字とカード絵

ホームのデッキ枚数・コストの太字までこげ茶へ揃え、クリームの面で白文字が溶ける問題を修正。PC/スマホ各15画面を再撮影し、文字・余白・見切れを確認した。

カード比較はcard-comparison.png。既存の歩兵・ドルイド・竜騎兵・骸骨兵・聖剣・火球と、新規の番人・樹人・竜鱗兵・ゾンビ・聖鎖の剣・聖火球を並べ、PNG原画と配信WebPも併記した。

- 太いこげ茶輪郭、金/銀/青/葉色の温かい色、可愛い顔と短い手足を確認。樹人や竜の非人間シルエットは役割に合わせて維持。
- 番人/竜鱗兵は大きい頭と短い胴体で既存のちび兵士と並べる。ゾンビの空の目や顔色はキャラクターの特徴で、圧縮で生じた変形ではない。
- 武器は道具自身、聖火球は現象を主役にし、人物を追加しない。既存火球の顔をすべての魔法へ強制しない。
- カード用WebPは表示画素の差がゼロ。隣接セルの絵の端が見えた竜鱗兵は、表示時のセル境界クリップで除外した。顔や原画の輪郭を修整していない。

## 検証

- 関連する既存テスト37件、画像/配線テスト6件。
- 5サイズの操作テスト。PCでは全200取得ノードを実座標クリックし、選択IDと各詳細の接続先一覧が元データと一致。286辺の端点・隣接関係と、曲線の重複がないことも確認。
- 実PWAキャッシュを作成し、通信を切ってホーム再起動・ツリーの開閉・WebP復号が成功。原画のキャッシュ混入ゼロ。
- 3D有効・降参なしの自然決着が成功。兵士を1枚出し、その後は通常のUIでターンを終了する戦略。11手番でp1がcastleDestroyedにより勝利し、結果表示と再戦が成功。Gameの状態を書き換えず、演出時間だけスキップ設定を使用。エラー/同期警告ゼロ。
- WebKitは取得して起動を試したが、libharfbuzz-icu等の共有ライブラリがなく起動不可。管理用パッケージヘルパー/sudoがなく、ユーザー領域へのパッケージ取得も既存索引に対象がなく失敗。webkit.jsonに実際の起動ログを保存。**iPhone/WebKitで動作確認済みとはしない。**
