## 共通UIのルール

| 要素 | ルール |
|---|---|
| ボタン | 最低44px、主操作は金、通常はクリーム、2pxこげ茶枠、2〜3pxの底面。押下時に沈む |
| パネル/ダイアログ | クリーム/羊皮紙、2px茶枠、12px角丸、既存の影トークン |
| タブ/フィルタ | 選択は青地＋白クリーム文字。aria-selected/aria-pressedを保持 |
| バッジ/状態 | 輪郭・✓/＋/!・線種を併用。色だけに依存しない |
| アイコン枠 | 無地クリーム＋茶輪郭。STARTは既存王国紋章 |
| 見出し | 茶文字、金の罫線。ツリー上部は王国の青い旗色 |
| 余白/角丸 | 既存spaceとradiusトークンを使用。地図の読み取り領域は装飾を抑える |
| 発光 | 通常操作には追加しない。既存の魔法/レア演出を維持 |

## ツリーの表示・操作

- 通常=円、奥義=大菱形、横断=六角形、START=大きい紋章。200取得ノード＋STARTを保持。
- 取得済み=青＋✓、取得可能=金茶の太枠＋、条件不足=赤茶破線＋!、未接続=点線＋灰色アイコン。
- PCは全体を初期表示。スマホ/タブレットは取得済み末尾またはSTART周辺から開始し、全体ボタンで一覧へ。
- ノード操作領域はズームによらず48 CSS px以上。縮小時の重なりは最も近い中心を選ぶ。密集箇所は検索/取得可能一覧/拡大も利用できる。
- STARTと同じ座標だったX21と、その近傍のX27は表示座標のみ左右へ退避。データ・辺・コスト・条件には変更なし。
- ピンチ/ホイール/ボタン拡大縮小、パン、ダブルタップ拡大、全体、現在地を用意。単タップはダブルタップの判定のため320ms待って詳細を開く。
- 小画面の詳細は下部シート。ランドスケープでは高さを確保する浮動パネル。アクションはシート下部に残す。
- キーボードはTabで図に入り、矢印で近いノードへ、Enter/Spaceで詳細、Escapeで閉じる。ダイアログ内Tab循環と終了時フォーカス復帰を追加。
- SVG部品は一度だけ作成。ズーム中はviewBox・当たり領域・小さいCanvasミニマップを更新。画像追加やノードごとのアニメーションループはなし。

## 未対応と提案

- 実機のiOS Safari/Androidでの片手操作、読み上げ、長時間利用の評価は今後必要。Chromiumの画面サイズ/実タッチイベント検証は実施。
- 全カードの絵柄を1枚ずつ審査する作業と、クラシック/新規陣営カードの代替表示の解消は一覧・プロンプトまで。対応コードの追加は本体実装との調整後に行う。
- 専用の横断/情報/墓地アイコンはP2候補。現行のアイコンと形状で機能を維持。
- 200ノード全体表示ではIDと名前を省略する。拡大・検索・系統/取得可能フィルタで読む。縮小状態の全ノードを同時に44pxの見た目へ膨らませることはしない。
- 3Dモデル自体と4陣営固有の魔法表現は既存のもの。UIのために3D素材を再制作していない。
- mainへpush/mergeしない。変更対象はUI・監査資料・UI検証のみ。`js/game/`, `data/`, `server/`, `tests/`, `js/main.js` は変更しない。
