## 判断メモ
- 追加の通常攻撃（U03・U08・X41・F01）は反撃なしの1回の攻撃（`Tactics.strike`）。威力50%は基礎威力を切り捨て（最低1）で減らしてから会心を判定。進軍の追加ステップで相手とぶつかったときだけ既存の `fight`（反撃あり）を使う。
- 通常攻撃の履歴を使う U02・X39・X43 は、命中の瞬間に呼ばれる mods（hitBaseAdd）に状態を持たせている（命中前の盾・HPや、命中した事実は解決後のイベントでは取れないため）。0を返すので威力は変えない。
- 城への固定ダメージの source は `{ kind: 'skill' }`。`ENEMY_CASTLE_SOURCES` に入っていないので、D系統の軽減・致死防止（D04・D06・D08）は通らない（直接攻撃でないので D04/D06 は通さない方が仕様に合う。D08 の「敵由来の致死」には効かない点だけ統合時に要確認）。
- 帰結：到達した兵士が残らない（A03・A06）、通常攻撃が同じ道にしか届かない（K01）、固有能力がない（X06）、罠がない（F02・F05・F06・F08・X42）は既存仕様の制約。
