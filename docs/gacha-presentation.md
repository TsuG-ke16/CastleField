# ガチャ演出（Phase 1–3）

## 実装

- Phase 1: ガチャトップ中央の宝箱、ズーム・光の収束・開封・カード出現、単発結果、レアリティ別の光。
- Phase 2: 10連の2D一覧、エピック以上のみ1枚ずつ先行演出、NEWとサーバーの重複変換ポイント、スキップ、タップ早送り。
- Phase 3: 結果をタップして1枚をCSS 3D観賞。ドラッグで傾ける、スライダーで回転、裏返す、角度を戻す。レジェンドの金の光輪とスペシャルの虹色装飾。

現在の景品は対戦カードではなく見た目用スキン。既存のコイン・排出率・天井・10連保証・重複変換を維持した。石への通貨変更、景品やスペシャル排出枠の追加は行っていない。

## 状態と負荷

`GachaPresentation` は確定済みの `results` を表示するだけで、抽選・残高更新を行わない。状態は charge → open → card → results ⇄ inspect。10連は高レアだけをcard段階で表示する。スキップとEscapeはresultsへ進め、結果画面のEscapeで閉じる。タイマーは遷移・終了ごとに破棄する。

通信中はCollectionViewのボタンと閉じる操作をロックし、同時送信を防ぐ。成功後にサーバーから残高を再取得する。演出は再描画の影響を受けない別要素に置く。通信失敗時に勝手に再送しない。通信が切れた時の確定済み結果は既存の履歴から確認できる。

宝箱と表示中のカード1枚はCSSの平面を立体配置。新しいWebGLコンテキスト、three.js、フレーム更新ループ、外部依存は追加していない。一覧は通常の2D DOM。粒子は16個に固定、`?fx=lite` で非表示。OS／既存設定の動き軽減では開封を省略して結果へ進む。

キーボード: Tabで演出内を巡回、Escapeで一覧／閉じる、回転スライダーは矢印キーで操作可能。観賞中は裏面の可視性に合わせて読み上げ対象も切り替える。

追加ダウンロードは不要。既存の絵柄・出典は `assets/STYLE.md` / `assets/CREDITS.md` に従う。

## 未実装・制限

- 実機スマホでのFPS・発熱・バッテリー測定は未実施。Chromiumの390×844と1280×900で検証。
- 宝箱はCSS 3D。専用GLBモデル、物理演算、音声・BGMの追加は未実装。
- スペシャル用の演出分岐は実装・フィクスチャ検証済みだが、現在のガチャ設定にはスペシャル景品がないため通常抽選では出ない。
- 裏面は共通の王国カード裏。スキン景品を観賞カードとして表示し、景品固有の別面情報は追加しない。
- PCでも既存ゲームの最大480pxの画面幅を維持する。10連一覧はPCで3列、スマホで2列、一覧だけがスクロールし閉じる操作は下部に残る。

## 検証

- `node --test`: 1,037件成功。
- `UI_TEST_FX=lite UI_TEST_FIELD3D=2d node ui-tests/collection.js`: 実APIでショップ・装備・単発・10連・残高・対戦へのスキン反映を確認。
- `node ui-tests/gacha-presentation.js`: 全レアリティ、早送り、スキップ、NEW/重複、回転・裏返し、Escape、演出軽減、終了後タイマー、通信中の連打・閉じる・通信失敗を確認。
- `node js/ui/build-precache.js`: オフライン用配信一覧を更新。

ブラウザテストにはPlaywrightとChromiumが必要。`UI_TEST_CHROMIUM` でブラウザ実行ファイルを指定できる。

## スクリーンショット

`assets/review/gacha/` にPC・スマホのトップ、宝箱、結果、観賞、裏面を保存。これらはガチャ演出テストの固定表示用データ（排出率を表すものではない）。既存PWAの配信対象には含めない。
