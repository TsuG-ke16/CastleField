# PR #202の既存ガチャへの開封・3D観賞追加

## 基準と変更範囲

基準はPR #202の最新コミット `ba3b524d84bd30e88142eb5a60764dfd88f9567c`（第5版）。`docs/navigation-redesign.md`、`docs/player-layout-v5.md`、Home/mainの接続、CollectionView、viewPlacement、collection.css、既存player-layoutテストを実装前に確認した。

他のPRも確認: #201/#198はmainに統合済み。#196は別系統の対戦外UI刷新でHome/main/indexに重なるが、今回の基準には採用しない。#197はその系統のジオラマ装飾、#199はQA、#200は独立スキルプレビューで、このガチャ演出とは統合しない。#194は音の変更で今回は対象外。

前回のPR #203はmainの古い画面を基準にしたため、#202が廃止した共通タブと二重導線を残していた。今回は#202を取り込み、#203のベースもそのブランチに変更。新設した宝物庫トップ・独自モーダルを撤去した。

### 画面・責務（#202から維持）

- 主ナビ「ガチャ」→同じページ内の1回/10連・天井・提供割合・履歴。ガチャを選ぶための別画面はない。
- 主ナビ「ショップ」→検索・購入・ポイント交換。ガチャや装備の操作はない。
- メニュー「スキン」→所持品の装備・解除とプレビュー。購入・抽選の操作はない。
- 抽選成功→既存の `dialog.gacha-reveal` 1つで開封→獲得結果→同じdialog内で観賞→一覧→閉じると元のガチャページ。

`Home.js`、`js/main.js`、`viewPlacement.js`、`css/collection.css`、ガチャトップの`renderGacha()`、ショップ/スキンの描画・処理は#202と同一。`CollectionView.reveal()`内のイベントだけを置き換え、同じdialogと既存結果カードを拡張する。新しいガチャページ、画面内タブ、入れ子のdialog、API呼出箇所は追加していない。

## 追加した演出

- 既存の「宝箱を開く」から、光の収束→宝箱ズーム→蓋が開く→カード出現へ進む。ボタンや宝箱のタップで早送り。
- レアリティ別の光。エピック以上は特別演出、レジェンドは金色の輪、スペシャルは虹色装飾。
- 10連は高レアだけ先行して1枚ずつ見せ、既存の2D結果一覧へ。NEW/重複ポイントはサーバーの値をそのまま表示。
- 「スキップ」は確定済み結果の一覧へ。「とじる」は既存dialogを閉じる。
- 結果カードをタップ/Enter/Spaceで観賞。CSS 3Dでドラッグの傾き、回転スライダー、裏返し、角度リセット。
- Escape: 開封中/観賞中は一覧、開封前/一覧では既存dialogを閉じる。ネイティブshowModalによる背景入力遮断とフォーカス制御を維持。
- 終了時・早送り時にタイマーを破棄。既存の通信中ロックと残高更新を維持。

抽選API・価格・コイン・排出率・天井・10連保証・重複変換は変更していない。現在の景品は対戦カードではなく見た目用スキン。

## 素材と負荷

| 素材 | 用途 |
