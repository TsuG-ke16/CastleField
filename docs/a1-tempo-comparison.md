## テンポの所見
- **1ターンのカード枚数**：クラシック none 1.84 → 3.27、4陣営 1.17〜1.35 → 2.72〜3.05。**コンボ率**（同じターンに兵士・武器・魔法・反応のうち2種類以上）：41% → 71%、4陣営 9〜23% → 61〜75%
- **MP不足率**：クラシック none 73% → 33%、4陣営 89〜98% → 9〜55%。**MP余剰**（終了時 MP≧50%）：none 1% → 42%。MP は「毎ターンほぼ使い切って足りない」から「半分くらいのターンで余る」に変わった
- **試合の長さ**（決着した試合の平均手番）：クラシック none 100.7 → 82.9、4陣営 69〜85 → 44〜53
- **コイン**：クラシック none 1試合の獲得 58.9 → 170.7（内訳：毎ターン 82.8・撃破 28.7・カード（徴税・貿易）25.3・金鉱 10.0・魔物 8.8・天候 6.7・略奪 5.3・城HP50% 2.7）。全部 smart の強化の購入（今の data/upgrades.json）に使われている
- **魔物討伐**：クラシック none 3.29 → 2.80／試合（試合が短くなったぶん減った）

## 4陣営の勝率の偏り（要確認・QA へ）

A1 後、王国・竜 76〜77%／森・魔族 24〜25% に開いた（前は 47〜55%）。要因を1つずつ戻して小さく測った（各陣営120試合・シード1。誤差 ±9% 程度）：

| 条件（それ以外は A1 前に戻す） | 王国 | 森 | 魔族 | 竜 |
|---|---|---|---|---|
| A1 前（全部戻す・確認用） | 46% | 50% | 57% | 55% |
| 攻撃魔法2回だけ | 46% | 47% | 49% | 53% |
| MP回復5だけ | 72% | 41% | 34% | 65% |

- 攻撃魔法2回は偏りを作っていない。**MP が豊富になること（回復5・新MP）で王国の切り札（MP5）と重い兵士が出しやすくなり**、**コインが増えて今の強化（訓練・とぎ石など兵士を強くするもの）を多く買えること**で、魔物をよく倒し兵士で押す竜・王国が伸び、森（魔物討伐 1試合1回前後）が落ちる
- 調整の方向（提示のみ・実装していない）：A2 の強化の置き換え（モード別・特殊強化18〜20コイン・即時強化1ターン1回）で「コイン→兵士の強さ」の比重が変わるので、**陣営の勝率は A2 のあとに QA で測り直すのがよい**。それまでの暫定の案：王国の切り札を MP6（上限20・回復5に対して）。森は魔物討伐が少ない（1試合1回前後）ぶんコインで遅れるので、魔物報酬の配分・撃破報酬の上限（3/ターン）を QA で確認（森の常時の精霊による撃破は cause "spirit" で、すでに撃破報酬の対象）
