## 2. 試した結果と調整の経緯（`tests/sim/factions.js`・シード1・smart 同士・席を入れかえ。1組み合わせ400試合）

森の精霊は、いまの設定（毎ターン）と、予定の2ターンに1回（`--spirit-every 2`）の両方で測った。**CPU（`js/game/strategies.js`）は、森の番人・樹人の配置と、防御カードの使い方があまり上手でない**ので、守りのカードの強さは実際の人間の遊びよりも低く出る（下の「迷った点」）。

調整の経緯（森、精霊2ターンに1回。森の勝率 対 王国／魔族／竜。変更前は 31／44／60）：
- 森狼（速さ3の獣・MP2）：75／67／75 … 安い速い兵士は強すぎたのでやめた（樹人に差し替え）
- 樹人 MP3・HP8・2枚：38／70／75 … 強すぎ → HP7・MP4・1枚に
- 薬草 +6・MP2・2枚：41／54／75 → +5・MP3・1枚に
- 最終（番人2枚・樹人1枚・薬草1枚・古木の根1枚。400試合）：36／56／66（平均 53%。変更前は 31／44／60 で平均 45%）。毎ターン精霊のとき：27／90／95 で、変更前の 27／86／96 と同じくらい。※1枚ずつ別々に測ると 平均 +2〜3 ずつだったが、全部足すと +8。2ターンに1回なら、森はまだ強めに出る（下の迷った点）

最終の表（400試合。Aの勝率）：

| 組み合わせ（A × B） | 精霊 毎ターン 変更前 → 後 | 精霊 2ターンに1回 変更前 → 後 |
|---|---|---|
| 王国 × 森 | 27% → 27% | 69% → 64% |
| 王国 × 魔族 | 62% → 66% | 62% → 66% |
| 王国 × 竜 | 60% → 63% | 60% → 63% |
| 森 × 魔族 | 86% → 90% | 44% → 56% |
| 森 × 竜 | 96% → 95% | 60% → 66% |
| 魔族 × 竜（魔族の勝率） | 42% → 46% | 42% → 46% |

平均手番は、王国×竜 88→85、王国×森（2ターン）90→96、森×魔族（毎ターン）60→60、竜どうし 96→89。（魔族は触っていないので、魔族のカードは変更前と同じ。）

竜は守りを足すと、CPU が防御カードを使わないぶん手札が詰まり、少し弱くなる（変更前の竜の勝率 対 王国／森（2ターン）／魔族 は 40／40／58 → 最終 37／34／54）。竜術師の魔法強化で補ったが、完全には戻っていない。

王国は、3枚合わせて平均 +1〜2（誤差の範囲）。

## 4. 迷った点

- **CPU の限界**：smart CPU は、森の番人（護衛）・古木の根・古竜の障壁・竜翼の身代わりを、ほとんど出さないか、出すタイミングが遅い。シミュレーションの勝率は、これらの守りの価値を低く見積もっている（竜が弱く出ているのは、このため）。人間が遊んだときの感触は別に確かめたい。
- **精霊の間隔**：森は毎ターンの精霊だと勝率が高すぎて、足したカードの影響が見えにくい。予定の2ターンに1回で調整した。それでも森は魔族に 44→56%、竜に 60→66% と、足したぶん強くなった（1枚ずつ足したときの合計より大きい）。「森は強さを足さない」なら、番人か古木の根を1枚減らすか、樹人をやめるとよい。間隔が決まったら測り直したい。
- **王国の天罰の光**：9は仮。MP5・使い切りなので「決め手だが1回だけ」にした。強さを足したくなければ 7 に下げてよい。
- **竜は弱くなった**：守りの役割を足すと、短期決戦のテンポが落ちる。竜術師で補ったが、まだ足りないなら竜の魔法の枚数か、竜術師の `spellBoost` を調整する。
- **画像**：`js/ui/factionArt.js` に新カードがないので、カード画像は出ない（神剣・勇者など、すでに載っていないカードと同じ扱い）。
